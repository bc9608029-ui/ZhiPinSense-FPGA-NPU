# DSP 显示数学与数据合同审查

范围：只读审查 ui_event.py 与 shared_variant/spectrum_backend.py；只在本目录运行合成数字数据。未访问 COM8、板子、SD、网络设备、SDR 或 RF。未修改共享 UI、接收器、模型或输入。没有本轮物理屏或 RF 验收结论。

## 实际错误（低优先级边界）
- 有效性判断依赖 display_iq[::4] 的分量峰值。非零信号若所有能量落在未抽中的位置，返回 spectrum_valid=False，连本来可计算的FFT也丢弃。最小复现 z[1]=1，其余零；8窗口复制。建议未来将全长信号有效性与星座抽样显示有效性分开。普通持续单音未触发。没有修改源代码。

## 显示语义
- RMS=sqrt(mean(|z|²))、peak=max(|z|)、PAPR=20log10(peak/RMS)，数学正确；单位为恢复模型IQ单位，不是ADC计数、瓦或绝对RF功率。power_dbfs字段实际20log10(RMS)，没有满量程校准；不应展示为绝对dBFS。noise_floor_dbfs实际是相对峰值谱的median，应标Median dB rel，不能解释成噪声底或SNR。clip_ratio和snr_est_db固定0是占位，不能作为实测零削顶或0dB SNR证据。
- FFT为1024点Hann窗，fftshift后负频在左正频在右；256显示桶每桶平均4个线性功率，再取10log10、峰值归零、最低-80dB、四分之一dB量化。这是相对功率谱，不是经窗能量/采样率归一的功率谱密度每Hz。
- 后端按最大I/Q分量缩放到16384并量化，返回u64功率除scale²恢复模型域功率单位：量纲正确。缩放与标签无关，不改变推理tensor；本轮未调用硬件或驱动，不能独立重证此前硬件误差。

## 设计限制
- 星座256点来自1024点每4点抽样，I为实部Q为虚部；分量峰值自动缩放到30000。不含载波/相位/符号时钟恢复、匹配滤波或符号判决，不能承诺标准解调星座。8窗口算术平均要求窗口为相同帧重复；若不同相位帧输入，可能抵消。这是明确输入合同，不应泛化为任意八帧。
- Fs固定2.56MS/s，FFT间距2.5kHz，显示桶10kHz；物理采样率改变时必须同步合同。
- -20dB带宽是首末过阈值桶之间的总跨度，含中间空隙，不是99%积分占用带宽，也不是active桶数乘桶宽。Hann窗及聚合桶会拓宽单音。
- centroid使用每桶平均频率乘桶功率，属于近似，单个FFT样点到桶中心偏差最多3.75kHz；本测试±200kHz单音均得到约+2080.078Hz误差。不是频率估计精度承诺。
- 零信号明确invalid，避免虚假的0dB满谱；暂停/无信号应配合LAST CAPTURE说明旧图。
