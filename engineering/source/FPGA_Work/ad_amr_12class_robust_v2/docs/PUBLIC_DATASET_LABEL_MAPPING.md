## 3. 结论

### 3.1 精确共享子集（7 类，可直接报 shared-subset 指标）

```
OOK, 4ASK, BPSK, QPSK, 8PSK, 16QAM, 64QAM
```

### 3.2 候选映射（默认不合并，需分布核对后才决定）

```
AM-DSB-WC → AM-DSB（核对载波/调制深度/消息带宽分布）
FM        → WBFM  （核对频偏分布是否落在 [10000,22000]Hz）
```

### 3.3 本项目有、公开数据缺（5 类，不填造）

```
2FSK, GFSK, WBFM, AM-DSB, OFDM
```

（FM 若不通过核对，WBFM 也归入缺失；AM-DSB 若 AM-DSB-WC 不通过核对，也归入缺失。）

## 4. 使用规则（冻结）

- 公开数据只用于 **shared-subset 跨域验证**与 **trunk 预训练**；不直接计算完整十二类总分。
- 候选映射（AM-DSB-WC→AM-DSB、FM→WBFM）在完成分布核对前**不得**进入任何指标。
- 公开数据缺的类别**不填造结果**，不混入目标头训练数据（避免 source 签名成为标签捷径——这是 V1 data-v3 的既有红线，见 `datasets/modulation_generator.py` 头部注释）。
- 采样率/窗口长度/归一化差异需在导入时对齐（RadioML 是 1024×2 实数 I/Q，`(1024,2)`→`iq[2,1024]` 转置，见 `radioml2018_dataset.py` 的 `raw.T`）。
