## 0. 判责结论（一句）

**PRIMARY VERDICT：`MIXED_PREPROCESS_AND_MODEL_DOMAIN`**

- **分量一（预处理可修复的谱结构失配）**：把真实 QPSK 带宽收窄到 RadioML 的 −20 dB 占用带宽边缘
  （8.125 kHz 固定低通，训练域导出），FP32 模型对真实 QPSK 的 top-1 **从 0/78 恢复到 35/78（44.9%）**，
  且不伤训练域（RadioML golden 179/200）。→ **带宽/脉冲成形失配是真实存在的可部署修复点。**
- **分量二（残余模型域泛化）**：带宽对齐后仍有 **43/78（55%）** 帧继续折叠进 QAM；且模型对每样本
  DC（|DC|≈0.086）的去除使**自身训练域** golden 崩到 55.5%——无归一化层模型对合成域精确数值剖面
  **过拟合**。→ **单纯预处理不足以完全修复，需要真实域微调。**

**CAVEAT：`INSUFFICIENT_INDEPENDENT_SESSIONS_FOR_GENERALIZATION_CLAIM`**
本结论的“真实域”证据仅来自**单次捕获会话** `rml23_capture_39e5_final_1773383076`（78 帧）。
**不得**据此断言“模型对所有真实 QPSK 泛化失败”或“带宽对齐对所有真实信号有效”——这可能是该发射机/
采集链路/当次条件下的表现。补足 §4 采集计划前，泛化结论不成立。

## 2. 判责分解（为什么是 MIXED，而非纯单边）

### 2.1 排除：`PREPROCESS_CONTRACT_MISMATCH` ❌
训练加载器 `__getitem__` 仅 `ascontiguousarray(raw.T)`、**无归一化**；真实帧本就是 `[I,Q]` planar。
Stage C 变换 #12（精确训练加载器）= 恒等。**输入格式/归一化契约无错配**（Stage A `normalization=none`
已证）。故问题不是“部署漏了某步训练预处理”。

### 2.2 排除：纯 `MODEL_DOMAIN_GENERALIZATION_REQUIRES_REAL_DOMAIN_FINETUNING` ❌
因为存在一个**合法、固定、训练域导出、可部署**的预处理（带宽对齐）能恢复 ~45% 真实 QPSK 且不伤
训练域——这证明失败有**可修复的谱结构失配分量**，不是“完全只能靠重新训练”。

### 2.3 命中：`MIXED_PREPROCESS_AND_MODEL_DOMAIN` ✅
- 预处理分量：带宽/脉冲成形失配（−3dB 8.0 vs 6.75 kHz；`|x|²` 干净谱线 vs 抹平；PAPR 3.57 vs 4.39 dB）。
- 模型分量：带宽对齐后仍 55% 折叠进 QAM；DC 脆弱性暴露无归一化层的合成域过拟合。

## 3. 与上一轮三后端判责的关系（refine，不矛盾）

上一轮 `MODEL_DOMAIN_GENERALIZATION` 判责**正确且仍然成立**：三后端（FP32/Host/NPU）对真实 QPSK
全判 QAM、板端 NPU 与 Host 量化**逐位一致**，故**根因在模型而非板端/量化/编译/输入缓冲**。
本轮 Stage A–C **不推翻**该结论，而是把“模型级失败”**分解**为：一个可部署预处理可修的谱失配分量
（~45%）+ 一个需真实域微调的残余域泛化分量（~55%）。二者方向一致、层次不同。

## 4. 真实域数据采集计划（单会话不足，须补足）

> 目的：把“该发射机/该会话”升级为“真实 QPSK 域”，支撑（a）带宽对齐预处理的鲁棒性验证、
> （b）真实域微调（若批准）。**红线：禁拿这 78 帧直接训练**（过拟合单次采集 + 其他类别灾难性遗忘）。

1. **独立会话**：≥ 3–5 次**独立**采集会话（不同时间 / 不同射频链路 / 不同发射机 / 不同天线），每次
   记录完整 RF 参数（`--rx-lo --rx-bw --rx-gain --nco-offset`、采样率、前端型号、线缆/衰减）。
2. **逐类别覆盖**：23 个部署类按序采集，**优先 QPSK 与 16/32/64/128/256-QAM**（当前混淆高发区），
   每类 ≥ 30 帧；含 **BPSK/QPSK 标签错位守卫**（source=3/4 不互串）。
3. **多条件**：每类在（高 SNR、−3dB 带宽 6–9 kHz、多档 CFO 0/±250/±500 Hz、不同脉冲成形）下各采集，
   以区分“带宽可修”与“模型域不可修”边界。
4. **冻结独立 held-out 会话**：至少 1 次会话**全程不碰**（不用于任何 cutoff/预处理/微调选择），
   只在最终验收时**一次性**读取，作为泛化证据。
5. **逐帧 SHA256 manifest**：所有采集帧记录字节 SHA，与输入/输出台账一致（沿用本目录 `input_sha256`
   纪律）。
