# Stage C — 合法预处理消融（12 项，全局 / 类别无关 / 可板端部署）

**绑定指令** 39e5 · **日期** 2026-10-11 · **输出目录** `diagnostic_qpsk_39e5_stage_abc/`
同一 FP32 ONNX、同一 24 类标签序、零权重改动。每项变换**对 78 帧真实 QPSK 统一施加**（不逐帧挑最优、
不按真实标签选择、不类别专用、不多数表决、不改标签序、不手工改 logits），并在同一变换下复测
**RadioML 合成 QPSK golden**（防“救回真实域却毁掉训练域”的伪修复）。

---

## 0. 一句话结论

- **12 项合法预处理中，唯一能实质救回真实 QPSK 的是“带宽对齐低通”**（把真实信号带宽收窄到
  RadioML 的 −20 dB 占用带宽边缘 ≈8.125 kHz）：**35/78（44.9%）** 恢复为 QPSK（基线 0/78），
  且 RadioML golden 仍 179/200（89.5%）——证明这是**合法、可部署、训练域导出**的变换，而非随机扰动。
- **其余 11 项（DC 去除 / RMS / CFO / 相位 / IQ 交换 / 共轭 / 循环移位 / 精确加载器）均 ≤1/78**，
  证实 Stage B 的结论：**不是缩放 / 相位 / 正交 / DC / 格式问题**。
- **模型对 DC 极其脆弱**：去除 RadioML 的每样本 DC（|DC|≈0.086，~9% RMS）使 golden 从 200/200
  崩到 **111/200（55.5%，66 帧翻成 32PSK）**——这是无归一化层模型对合成域精确数值剖面的**过拟合印记**。

**结论方向**：存在**可修复的谱结构失配分量（带宽，~45%）** + **残余模型域泛化分量（~55%）** →
  最终判责 = **MIXED_PREPROCESS_AND_MODEL_DOMAIN**（见 `JUDGMENT.md`）。

## 2. 关键判读

### 2.1 变换 #12（精确训练加载器）= 恒等 → 预处理契约无错配
`datasets/radioml2018_dataset.py::__getitem__` 只做 `ascontiguousarray(raw.T)`、**无任何归一化**；
真实帧 `.f32` 本就是 `[I,Q]` planar（= `raw.T` 形式）。故“精确复刻训练加载器”对真实帧是**恒等**，
且基线即 0/78。**证明真实捕获已是训练输入的精确格式，问题不在格式 / 归一化契约**（Stage A 已证
`normalization=none`、unit-RMS）。

### 2.2 变换 #11（带宽对齐）= 唯一实质救回 → 谱结构失配是主分量
把真实信号收窄到 RadioML −20 dB 占用带宽边缘（8.125 kHz 单边）后，QPSK 恢复 **35/78（44.9%）**。
这是**训练域导出**的固定低通（cutoff 取自 RadioML 占用带宽，非在测试帧上 argmax）。

**cutoff 敏感性（透明报告，非挑优）**：

| cutoff (kHz) | 真实 QPSK/78 | RadioML golden/200 |
|---|---|---|
| 6.0 | 0 | 0 |
| 7.0 | 0 | 6 |
| 7.5 | 0 | 54 |
| **8.125（−20 dB 边缘，principled）** | **35** | **179** |
| 8.5 | 41 | 200 |
| 9.0 | 30 | 200 |
| 10.0 | 1 | 200 |

效应是**宽峰**（8–9 kHz 区间 30–41/78），非尖刺；cutoff<7 kHz 过狠（连 golden 一起毁），
>9.5 kHz 过轻（效应消失）。**我采用 8.125 kHz（训练域 −20 dB 边缘）作为唯一合法数值**，8.5 kHz 仅作
透明敏感性参考，**不据其宣称泛化成绩**（符合“不用测试帧挑超参”红线）。

### 2.3 变换 #2/#4（DC 去除）暴露模型过拟合印记
两域**每样本 |DC mean| 分布相近**（RadioML 0.086±0.046，真实 0.072±0.045，均 ~7–9% RMS），
故 DC 不是两域判别量。但去除 RadioML 的每样本 DC 使 golden **200→111（55.5%）**、66 帧翻成 32PSK——
**无 BatchNorm 的模型把绝对 DC 电平当成分类特征**，对 0.086 量级的扰动都极脆弱。这是**合成域精确数值
过拟合**的强证据，也是“仅微调/仅预处理未必足够”的旁证。

### 2.4 变换 #3/#5/#6/#7/#8/#9/#10 → 均无效果
RMS 归一化（#3）、固定/估计 CFO（#5/#6）、相位旋转（#7）、I/Q 交换（#8）、共轭（#9）、循环移位（#10）
均 ≤1/78 且 RadioML golden 保 100%（除估计 CFO 199/200）。**再次确认**：真实 QPSK 被折叠进 QAM 与
**缩放 / 频偏 / 相位模糊 / 正交 / 采样相位**均无关，而与**谱占用宽度 + 脉冲成形纹理**强相关。
