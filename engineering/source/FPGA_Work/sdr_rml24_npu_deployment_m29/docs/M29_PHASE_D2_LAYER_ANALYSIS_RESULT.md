## 1. 结论（TL;DR）

**首次偏离层定位失败——因为不存在"单个敏感层"。** AM-SSB-SC 崩塌是**分布式的 INT8 激活动态范围失配**，根因在 AM 族输入幅度本身：

1. **输入层就分道扬镳**（bit-exact 对齐，cos=1.0）：AM-SSB-WC 的 I/Q 幅度 `[-24.5, 43.4]`，是"其它 22 类" `[-3.8, 4.0]` 的 **≈10×**；AM-SSB-SC `[-12.1, 11.4]` 是 **≈3×**。
2. 这一幅度差在第 1 个卷积输出 `den.stem_out` 就体现为 24.8 dB（WC）/ 13.6 dB（SC）的 pooled SQNR 差距，并**贯穿全部 33 个边界**单调累积（AM 族每层比"其它"差 8–25 dB）。
3. 因此不存在"首次明显偏离后其余层干净"的悬崖；也不存在可定向 bf16 的最小敏感层集合。**FC1（op177）不是敏感层**——前序 4 样本初步结论（fc1 崩塌）是小样本假象，1536 全量下 FC1 的 SC cos=0.912 仅略逊于深特征层，且"其它"类在 FC1 处反而更差（cos 0.963）。
4. **与实验 A 的可复现性自洽**：head 已 bf16 仍 −31.3pp，是因为 AM-SSB-SC 与 AM-SSB-WC/OOK 在 logits 上**本就近并列**（margin≈0），而累积激活误差使其 logits 的 pooled SQNR 只有 ≈10 dB（其它类 ≈22.7 dB），足以翻转近并列决策；AM-SSB-WC 之所以在实验 A 恢复（±3.1pp），是因其 logits 边际大、对误差鲁棒，而非其激活更干净（本分析显示 WC 激活误差反而**更大**）。

## 4. 动态范围证据（fp32 vs int8 上界）

int8 上界 = `scale×127`（per-channel），超界即裁剪/压扁。关键层：

| 边界 | SC fp32 | SC int8 | WC fp32 | WC int8 | other fp32 | other int8 |
|---|---:|---:|---:|---:|---:|---:|
| input | [-12.1, 11.4] | 同 | [-24.5, 43.4] | 同 | [-3.8, 4.0] | 同 |
| den.stem_out | [0, 18.3] | [0, 6.78] | [0, 36.7] | [0, 6.78] | [0, 6.30] | [0, 6.30] |
| denoised | [-24.0, 7.3] | [-8.5, 6.2] | [-57.4, 38.1] | [-8.5, 6.9] | [-5.3, 4.7] | [-5.3, 4.8] |
| feat7.out | [0, 18.3] | [0, 14.2] | [0, 58.2] | [0, 13.7] | [0, 26.4] | [0, 14.7] |
| mean | [0, 6.80] | [0, 7.00] | [0, 17.1] | [0, 7.00] | [0, 7.55] | [0, 7.00] |

- AM 族 fp32 上界远超 int8 上界（denoised 层 WC 达 57.4 vs int8 8.5 = **6.7×**；mean 层 WC 达 17.1 vs int8 7.0 = 2.4×），被 per-channel 固定 scale 裁剪/压扁。
- "其它"类 fp32 上界与 int8 上界基本吻合（denoised/mean 层均在界内），故 22 类保持干净。
- 饱和率本身不高（≤0.12%）——说明是**重尾分布**：绝大多数元素落在 int8 界内，少数极端幅值被裁，但恰是这些大值主导了误差平方和，拖垮 pooled SQNR。

## 5. 首次偏离判定（规则 A）

- **第一个明显偏离层 = `den.stem_out`（op510，第 1 个卷积输出）**，不是深层。WC 在该层即与"其它"拉开 24.8 dB，SC 拉开 13.6 dB。
- 此后**逐层单调累积**，无恢复、无悬崖；深特征层（feat6/feat7）只是累积的末端，SC 在 `feat7.conv2` 达最低 2.8 dB。
- **因此"最小敏感层集合"退化为空**：不存在"改一层/一组即可恢复"的候选。任何单层/单组 bf16 都无法消除 AM 族从输入层就引入、贯穿 28 卷积的分布式动态范围失配。

## 6. 对整改路径的判定

1. **规则 B（分组 bf16 二分）前提不成立**：分组二分假设误差局域化，本分析证伪（误差在 denoiser 与 features 四组间近似均匀分布，AM 族每层皆劣 8–25 dB）。定向 bf16 单层（如 op177 FC1）预计无效——FC1 输入 `mean` 层 SC 已 4.7 dB / cos 0.878，FC1 无法优于其输入。
2. **CPU-fallback 风险（规则 E/F）**：若要覆盖"整个主干 bf16"才能恢复 AM 族，则 28 个 conv 的 bf16 在 ZG330 上存在关键算子回退 CPU 的实质风险，且本阶段无板上映射率手段（禁碰板）——不可作为"NPU 成功"路径。
3. **规则 C 约束下无 PTQ 出口**：根因是 AM 族幅度失配，唯一干净的 PTQ 出口是"含 AM 代表性样本的激活校准"（重校 activation scale），但规则 C 明文禁止换校准集/改校准；规则 D 禁止用最终测试指标选参。二者皆锁死。
4. **结论 → 规则 F 触发**：最小敏感层集不存在、无法在不重校/不全量 bf16（CPU fallback 风险）下恢复 AM-SSB-SC。**建议停止 PTQ 补救，提交本证据申请 QAT**（激活感知量化训练，令 AM 族幅度在训练中显式进入 scale 学习），**不自动重训**。
