# M28_0 RF 路径与 EMI 审计（RF Path & EMI Audit）

任务 id="39e5" · M28-0 · 只读、证据驱动的 RF/EMI 评估。**本文件不输出任何 EMI/EMC PASS**（红线）。

---

## 1. RF 路径（Pluto → SMA 穿板座）

### 1.1 基线路径

- Pluto RX SMA → 短同轴（SMA 母-母 或 SMA-IPEX+SMA）→ 顶部 SMA Female Bulkhead。
- Pluto TX SMA → 同上。
- 目标：路径最短、连接器数量最少、弯曲半径不过度。

### 1.2 关键参数（证据）

| 项 | 值 | 来源 |
|---|---|---|
| Pluto 接口 | RX + TX，各 50Ω SMA | E6（ADI wiki 存档） |
| RX 绝对最大输入 | +2.5 dBm | E6（AD9363 手册） |
| TX 默认衰减 | −10 dB | E6 |
| Pluto 外壳 | 塑料，**无屏蔽** | E6/E8 |
| 频率范围 | 325MHz–3.8GHz（固件改 ~70MHz–6GHz） | E6 |

### 1.3 风险与处置

| # | 风险 | 说明 | 处置 |
|---|---|---|---|
| R1 | **SMA 穿板座机械应力** | 顶部 SMA 频繁插拔，机械力由面板承担 | 穿板座必须有面板侧锁紧螺母 + 外壳结构支撑；**不得仅靠同轴线吊着** |
| R2 | **SMA 接地路径未定义** | 穿板座外导体应与外壳形成接地，否则外皮成天线 | 结构件（金属面板/局部接地铜箔）或塑料面板下加接地平面，待材料审计决定 |
| R3 | Pluto 塑料壳**无屏蔽** | 板载 RF 前端对箱内数字/电源噪声敏感 | 布局拉开 + 局部屏蔽（非全隔舱） |
| R4 | RX 前端过载风险 | 超过 +2.5dBm 损坏前端 | 外壳上应加**警示标贴**（RX 输入上限），非结构件 |
| R5 | 连接器损耗/失配 | 每个 SMA 转接引入插损与反射 | 减少转接数量，首选用 SMA 母-母 直连，避免多级转接 |

## 2. EMI / EMC 分区（概念）

- **RF 区**（顶部，Pluto + SMA）：远离电源变换与高速时钟。
- **电源区**：DC 输入、DC/DC（若有）置于对角，尽量远离 RX SMA。
- **数字区**：主控板、USB/HDMI/RJ45。

### 2.1 屏蔽策略（概念，非结论）

| 方案 | 说明 | 评估 |
|---|---|---|
| S1 布局拉开距离（首选） | 分区 + 距离衰减 | 成本低、体积适中 |
| S2 局部屏蔽罩 | Pluto/前端局部加金属罩 | 需接地，待实测 |
| S3 全金属外壳 | 整体铝壳 | EMI 最佳但成本/重量/加工最高，且需开窗/绝缘处理 |

**结论：S1 为基线，S2 可选，S3 仅在用户明确需要且接受成本时评估。** 金属外壳并非"EMI 通过"的充分条件，故不输出任何 EMI PASS。
