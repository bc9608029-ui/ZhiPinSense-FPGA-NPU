## 2. 关键风险

| # | 风险 | 说明 | 处置 |
|---|---|---|---|
| F1 | **屏幕型号未知 → 开窗无法生成** | 最显眼、最难返工的切口 | 用户实测 C-1~C-8 前**不画开窗** |
| F2 | 触摸禁压区与前面板压边冲突 | 若屏带触摸，边框压感区被前面板压住会失灵/误触 | 测 C-7 禁压区，压边让位 |
| F3 | HDMI/触摸接口朝向决定前面板与主板间距 | 屏接口朝下/侧影响内部净空 | 测 C-5/C-6 |
| F4 | 指示灯/按钮与屏边缘间距 | 视觉拥挤、误触 | 待屏外形确定后统一排布 |
| F5 | 720P 限制 | 板载 HDMI 720P@60 原生，1080P 闪屏风险 | 选 ≤720P 屏或验证（见线缆审计） |

---

## 3. 前面板与主箱体连接（概念）

- 前面板建议独立于主箱体前盖，便于屏幕单独装拆。
- 屏固定方式（铜柱/胶贴/卡扣）待屏安装孔（C-4）确定后选择。

## 4. 铭文/标识

- 非结构件，仅需在最终前面板表面做丝印/激光雕刻，不影响本阶段 CAD 门禁。
- 注意：**不生成任何"智频感知"成品图当作加工图**；铭文仅为文字要素，无尺寸冻结。
