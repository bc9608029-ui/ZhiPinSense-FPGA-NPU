# M28_0 用户实测参数清单（User Measurement Checklist）

任务 id="39e5" · M28-0 · 本清单列出**进入参数化 CAD 前必须由用户实物测量**的参数。
**没有这些实测值，不得生成任何开窗/螺柱/加工尺寸**（红线：不得用照片估算值当加工尺寸、不得用相似板替代）。

> 测量工具建议：游标卡尺（≥150mm）、钢直尺、塞尺、照相机（六面 + 特写）、非导电直尺垫。
> 记录要求：每个数值附照片编号 + 单位 + 读数（毫米精确到 0.1mm，接口中心坐标以板边为基准）。

---

## A. 主控板（裁决用哪块板后测）

### A1 板卡身份裁决（阻塞级，先做）

| # | 待裁决 | 选项 | 依据 |
|---|---|---|---|
| A1-1 | 实际入壳板卡 | ① 悟净 **Lite**（202×150，无 NPU）② 悟净 **整机/FPAI**（233×139，有 NPU） | 冲突 C1：任务书"Lite"与"NPU"自相矛盾 |
| A1-2 | 入壳板数量 | 1 块 / 2 块 | 影响内部空间与走线 |

### A2 板卡机械参数（手册未给，必测）

| # | 参数 | 说明 | 用途 |
|---|---|---|---|
| A2-1 | 板卡外形长/宽（实测复核） | 卡尺实测，与手册 202×150 或 233×139 比对 | 确认手册值与实物一致 |
| A2-2 | 板厚 | 塞尺/卡尺 | 螺柱高度计算 |
| A2-3 | **安装孔坐标**（相对板左下角原点，X/Y 各 mm） | 每个孔中心坐标 + 孔径 + 是否镀金/接地 | **螺柱定位，阻塞 CAD** |
| A2-4 | 安装孔数量与布局 | 全板逐个登记 | 支撑点选择 |
| A2-5 | 最高元件高度（含散热器+风扇） | 从板面到最高点 | 箱体内部净高 |
| A2-6 | 散热器外形尺寸 + 安装方式 | 长/宽/高/固定件 | 热设计与干涉 |
| A2-7 | 各边沿接口中心坐标 | HDMI/USB×4/UART/RJ45/DC/开关/指示灯 距板边位置 | 前面板/侧板开孔对位 |
| A2-8 | 插头插入后的包络（每接口） | HDMI 线、USB 线、网线插上后的总伸出长度与弯折半径 | 内部线缆避让 |

### A3 板卡电气（供电源审计交叉核对）

| # | 参数 | 说明 |
|---|---|---|
| A3-1 | DC 输入座（J37）型号/外径内径 | 配电源适配器插头 |
| A3-2 | 整板功耗（有功率计则测，无则查手册） | 供 DC/DC 与散热估算 |

## C. 7 寸 HDMI 屏（正面开窗阻塞级）

| # | 参数 | 说明 |
|---|---|---|
| C-1 | **屏幕型号/料号** | 拍照标贴，**型号未知禁止开窗** |
| C-2 | PCB 外形长/宽/厚 | 整体包络 |
| C-3 | **有效显示区（AA）** 长/宽 + 相对 PCB 位置 | 开窗对位 |
| C-4 | 安装孔坐标/孔径 | 屏幕固定 |
| C-5 | HDMI 接口位置/朝向 | 内部走线 |
| C-6 | 触摸接口类型/位置（USB? I2C? 排线?） | 触摸接入 |
| C-7 | 触摸禁压区（边框压感区宽度） | 前面板压边避开 |
| C-8 | 屏幕排线/驱动板是否与屏一体 | 内部空间 |

## 结论

- **A1（板卡身份）+ A2-3（安装孔坐标）+ C（屏幕型号）** 是三个阻塞项，缺一不可进入 CAD。
- 其余项可在 M28-1 参数化建模过程中按需补测，但**不得在测量前用估算值替代**。
