# M28_0 内部布局可行性审计（Layout Feasibility）

任务 id="39e5" · M28-0 · 比较内部布局方案，仅概念级，不含加工尺寸。

> 本文件所有几何均为**相对关系/方向性**描述，不含冻结的长宽高；任何引出尺寸均以 `CONCEPT ONLY / NOT FOR MANUFACTURING / DIMENSIONS NOT FROZEN` 标注。

---

## 1. 候选布局方案（概念）

### 方案 A —— 单层水平布局 + RF 分区（首选）

- 主控板平置于箱体底板（铜柱支撑）。
- **RF 区**：Pluto 靠顶部，RX/TX SMA 直接上穿顶板（路径最短）。
- **电源/数字区**：板卡电源输入、DC 座在左侧或后侧；RJ45/USB 走一侧。
- **显示区**：7 寸屏贴前面板内侧，HDMI + 触摸线由板卡引出。
- **散热**：风扇抽风，气流自底/前入、顶/后出。

优点：
- 结构简单、装拆直观（契合"可拆后盖"基线）。
- RF 路径最短，Pluto 与 SMA 距离最小。
- 单层便于维护 SD/JTAG/UART。

缺点：
- 箱体宽度由板卡长边决定（202~233mm），体积偏大。
- 板卡与 Pluto 之间的 USB 数据线需短（<0.5m，USB2.0 无中继）。

### 方案 B —— 双层叠放（备用）

- 主板在下层、Pluto（或屏幕驱动板）在上层，垂直叠放。
- 上层为 RF/显示，下层为电源/数字。

优点：
- 底面积小，更"便携"。

缺点：
- 板卡发热叠加，散热更复杂。
- 上层高度叠加需更大净高，装拆与维护困难。
- RF 线要跨层，路径变长。

**结论：方案 A 为基线，方案 B 仅在用户要求最小体积时评估。**

---

## 2. Pluto 固定方式（概念）

| 方式 | 说明 | 评估 |
|---|---|---|
| P1 **保留原壳**（首选） | Pluto 整体放箱内，用卡槽/压条/扎带固定，SMA 直接穿板 | 最安全：不破坏原壳、不引入接地/散热未知数 |
| P2 拆壳贴底 | 拆除塑料壳，PCB 直接螺柱固定 | 更薄，但需另行解决接地、散热、绝缘，风险高 |
| P3 外置 | Pluto 放箱外独立 | 违背"一体便携"目标，不推荐 |

**结论：P1 首选。P2 仅在用户明确要拆壳且补测接地/散热后才评估。**

---

## 3. RF / 电源 / 数字 分区（概念）

- **RF 区（顶部）**：Pluto + 2×SMA 穿板座，尽量远离开关电源与高速数字区。
- **电源区（一角）**：DC 输入、可能的 DC/DC，远离 RX SMA。
- **数字区（中部）**：主控板、USB/HDMI/RJ45。

> 频谱感知对噪声底敏感，分区目的是**降低电源噪声串入 RX**，但分区≠全金属隔舱（体积代价大）；优先用布局拉开距离 + 局部屏蔽，详见 RF/EMI 审计。

---

## 4. 尺寸包络（CONCEPT ONLY）

以下仅为**方向性估算，非加工尺寸**，用于判断"能否装得下"，**禁止**据此生成 CAD。

- **主板平面概念包络（M28-0.1 勘误）**：二者并集 **233 × 150 mm**（`max(202,233) × max(150,139)`），**仅作 PCB 概念占用区，不得直接作为外壳尺寸**。
- 外壳还需在四边/高度额外叠加（全部 TBD，不猜值）：HDMI/USB/RJ45/电源插头、SD 插拔、UART/JTAG 维护、线缆弯折、散热器高度、风道、壁厚、装配公差、螺钉操作空间。
- 净高：≥ 板卡最高元件高度 + 散热器 + 风扇 + 顶部 SMA 尾部。

> `CONCEPT ONLY / NOT FOR MANUFACTURING / DIMENSIONS NOT FROZEN`

---

## 5. 可维护性（详见装配/维护审计）

- 后盖可拆 → SD/JTAG/UART 可达。
- 屏幕/前面板尽量独立拆装，不连带主板。
- 风扇、SMA、DC 座为易损/常动件，留单独固定。

---

## 6. 模块化接口面板（M28-0.1 复审）

目标：减少外壳开孔对具体主板连接器坐标的依赖。

| 要素 | 结论 |
|---|---|
| 独立后接口面板 | **采用**：RJ45/DC/维护口集中在独立后板，换板只改后板开孔 |
| 可更换侧接口模块 | **原型暂不采用**，比赛版按需：侧模块增加成本与缝隙 |
| RJ45 面板延长线 | **谨慎**：需屏蔽+接地（见下），普通线损 EMI/网口信号 |
| USB 面板延长线 | **可接受**：USB2.0 短延长（≤0.3m）带宽/供电可满足；过长供电压降 |
| HDMI 保持内部连接 | **采用**：屏在箱内，HDMI 不外引，减少面板开孔 |
| DC 固定独立电源面板 | **采用**：DC 接口与电源区同板，避开 RF |
| UART/JTAG 维护盖板下 | **采用**：隐藏维护区，后盖可拆即达 |

**必须评估项**：
- 延长线可靠性：RJ45 延长需屏蔽双绞 + 两端接地，否则 1000M 掉速/EMI；USB 延长供电压降随长度上升。
- USB 带宽与供电：USB2.0 短延长无碍；触摸/Pluto 供电靠板载 +5V，延长线电阻需 < 线损允许。
- RJ45 屏蔽与接地：面板侧 RJ45 座金属壳接外壳地，线缆屏蔽层连续，否则成 EMI 天线。
- 线缆长度：数据线尽量 <0.5m，RF 同轴最短。
- 插头防松：RJ45 自带卡扣；USB/DC 靠面板开孔 + 卡线座。
- 后盖拆卸：后板独立，拆后盖不牵动主板。
- EMI：开孔集中到独立面板，便于局部屏蔽。

## 7. 尺寸与便携性权衡

| 维度 | 精确板卡方案 | 最大包络通用方案 |
|---|---|---|
| 外壳尺寸 | 小 | 大 |
| 线缆长度 | 短 | 可能更长 |
| 散热优化 | 易 | 风道需重规划 |
| 兼容性 | 仅一种板卡 | 两种候选 + 后期换板 |
| 空间利用率 | 高 | 低 |

- **原型机推荐**：**最大包络通用方案**（便于换板试错，233×150 占位包络 + 通用托盘）。
- **最终比赛版推荐**：**按实际板卡优化**（外壳小、线缆短、散热易优化）。
- 判断准则：**不得只因为"能放进去"就认定最大包络更优**——最大包络牺牲了体积/线缆/风道，仅在原型迭代期划算。
