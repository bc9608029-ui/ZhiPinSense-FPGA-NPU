# M28_0 外壳方案审计（Enclosure Design Audit）

任务 id="39e5" · M28-0 · 只读审计。

> **勘误（M28-0.1）**：本文 §2 P1 与 §3 风险#1 已被 `docs/M28_0_1_ERRATA_REPORT.md` 修正——"板卡是否有 NPU"已从未知改为**确认**（板卡已跑通 NPU 模型）；当前未确认的仅为**载板机械版本与安装尺寸**。NPU 功能身份不再是阻塞项。

---

## 1. 初步方案"前面板 + 横向主箱体 + 可拆后盖"合理性

**总体方向合理，可作为基线。** 理由：

- "可拆后盖"契合板卡密度高、需频繁访问 SD/JTAG/UART 的维护需求（§十六）。
- 前面板放屏、顶部放 SMA 使 RF 路径最短（Pluto 靠上）。
- 横向主箱体与板卡长宽比（约 1.35:1）相符，单层即可容纳。

**但存在两点需在后续修正**：

1. "横向"若指单层平铺，箱体宽度 ≈ 板宽 + 两侧余量；板 202~233mm 长边会决定箱体较宽（见布局审计，Q9）。
2. 方案未明确 RF 区与电源区的物理隔离；作为频谱感知终端，噪声底敏感，建议在单层内做**布局分区 + 局部屏蔽**而非全隔舱（见 RF/EMI 审计）。

## 3. 最严重三个结构风险（详见各专项审计）

1. **载板机械版本与安装尺寸未确认（CRITICAL）**：NPU 功能身份已确认，但载板精确型号/PCB 修订版/实际尺寸/安装孔/连接器坐标/最大器件高度未实测 → 螺柱与连接器坐标无法定位。（原"板卡身份未定"已勘误）
2. **无安装孔坐标（CRITICAL）**：任何板卡，手册均未给安装孔坐标/孔径/板厚 → 螺柱位置无法确定，直接阻塞 CAD。
3. **屏幕型号未定（CRITICAL）**：7 寸屏型号未知 → 正面开窗（最显眼、最难返工的切口）无法生成。
