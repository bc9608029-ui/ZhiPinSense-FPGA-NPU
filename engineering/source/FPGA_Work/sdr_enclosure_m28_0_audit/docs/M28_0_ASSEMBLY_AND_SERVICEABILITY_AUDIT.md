# M28_0 装配与可维护性审计（Assembly & Serviceability Audit）

任务 id="39e5" · M28-0 · 审计装拆顺序与维护可达性（SD/JTAG/UART/复位）。

---

## 1. 装配顺序（概念）

1. 底板固定主控板（铜柱 + 螺钉）。
2. 固定 Pluto（保壳，卡槽/压条）于顶部 RF 区。
3. 顶部 SMA 穿板座 + 同轴线接 Pluto RX/TX。
4. 前面板固定屏幕（待屏安装孔）。
5. 布线：USB（主板→Pluto）、USB/触摸、HDMI、DC、风扇、按钮、LED。
6. 侧板/后盖合拢（后盖可拆）。

---

## 2. 可维护性关键点

| 维护项 | 可达方式 | 审计结论 |
|---|---|---|
| SD 卡 | 板载 TF 槽 | 需后盖拆开后可达，或开侧窗；**后盖可拆即满足** |
| JTAG（2×20-pin） | 板载 | 维护用，后盖可达即可 |
| mini-USB UART | 板载 | 同上，隐藏维护区 |
| 复位/按键 | 板载 | 隐藏维护区或引出 |
| 风扇 | 独立固定 | 易拆换 |
| 屏幕 | 前面板独立 | 不连带主板 |

---

## 3. 风险与处置

| # | 风险 | 处置 |
|---|---|---|
| S1 | 后盖合拢后 SD/JTAG 被挡住 | 后盖可拆为基线；关键维护口（SD）可考虑单独小开窗（待实测定位） |
| S2 | 屏幕拆装需先拆主板 | 前面板独立拆装 |
| S3 | 线缆松脱/干涉 | 线夹/扎带座固定，预留弯曲半径 |
| S4 | 拆后盖触碰 RF 同轴 | 同轴固定，避免与后盖干涉 |
