## 1. 发热源盘点（概念）

| 器件 | 发热 | 说明 |

---

## 2. 散热策略（概念）

| 方案 | 说明 | 评估 |
|---|---|---|
| T1 **主动风冷（风扇）** | 底/前入 → 顶/后出，贯穿主板散热器 | 首选：板卡已配散热器，加风扇最稳 |
| T2 被动散热（开孔对流） | 仅散热器 + 自然对流 | 体积/噪声小，但高温环境不可靠 |
| T3 导热外壳（金属壳） | 散热器贴壳 | 依赖金属材料（见材料审计） |

**结论：T1 主动风冷为基线，气流方向 = 底/前入 → 顶/后出。** 风扇型号/孔距/电压待测（D-1）。

---

## 3. 气流路径（概念）

- 进风：底盖/前面板下部开孔 + 防尘网。
- 出风：顶盖/后盖上部开孔 + 风扇抽风。
- 关键：进风与出风错开，避免短路回流；气流掠过主板散热器鳍片。

> 开孔孔径/位置/数量属加工尺寸，**待风扇与实测后定，本阶段不冻结**。

---

## 4. 风险

| # | 风险 | 说明 | 处置 |
|---|---|---|---|
| H1 | 风扇风量/压头不足 | 散热器翅片密，需一定压头 | 实测最高元件温度后选型 |
| H2 | 开孔致 EMI/异物 | 开孔过大会引入 EMI、异物 | 与 EMI 审计协同；加防尘网 |
| H3 | 屏幕背光发热与主板叠加 | 屏与板距离近 | 屏与板间留风道 |
| H4 | Pluto 无屏蔽且散热差 | 塑料壳热阻高 | 保留原壳时留对流空间；不拆壳则低发热可接受 |
