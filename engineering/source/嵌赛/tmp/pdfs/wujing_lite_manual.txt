1 开发板简介
  悟净 Lite（轻量版）开发板是基于复旦微电子 PSOC 系列高端芯片 JFMQL30TAI676H 开

发的平台产品。

主要特色：

1） 国产化器件比例 90%以上

     开发板上的主要芯片，其中包括电源模块、PSOC 芯片、DDR、Flash 和外围接口芯

  片等，全部采购于国内芯片厂商。可以为客户的方案设计和项目开发提供了参考。

2）板卡设计紧凑

  整板尺寸：202 (mm) x 150 (mm)

3）板上资源丰富

  主芯片：JFMQL30TAI676H

  PS DDR：1GB DDR3 PL DDR：2GB DDR3

  高性能接口：

                HDMI

4.13 USB 接口

   悟净 Lite 开发板上有 4 个 USB2.0 HOST 接口，USB2.0 收发器采用的是一个 1.8V 的，

高速的支持 ULPI 标准接口的 USB3320C-EZK 芯片，再通过一个 USB HUB 芯片 USB2514 扩展出

4 路 USB HOST 接口。PSOC 的 USB 总线接口和 USB3320C-EZK 收发器相连接，实现高速的

USB2.0Host 模式的数据通信。USB3320C 的 USB 的数据和控制信号连接到 PSOC 芯片 PS 端的

BANK501 的 IO 口上， USB 接口差分信号(DP/DM)连接到 USB2514 芯片扩展出 4 个 USB 接口。

2 个 24MHz 的晶振为分别为 USB3320C 和 USB2514 芯片提供时钟。4 个 USB 接口为扁型 USB

接口(USB Type A)， 方便用户同时连接不同的 USB Slave 外设(比如 USB 鼠标和 USB 键

盘），每个 USB 接口提供了+5V 的电源。

4.16 HDMI 输出接口
   HDMI 输出采用了 IO 模 HDMI 信号，输出可以达到 720P@60HZ 高清传输。实测 1080P@60HZ
的信号输出，有的显示器会存在闪屏的情况。因为在运行 1080P@60HZ 的时候，HR 的 bank
的时钟运行在 748.5M 的 TMDS 速率，超出了手册 HR 的 bank 的 IO 的最高 710M 的速率要求。

4.21 电源管理

   悟净 Lite 开发板采用适配器 AC~220V 转 DC-12V 供电。12V 输入经 DC 电源座 J37、拨码

开关 SW8、防反接保护二极管 D25 后，进入电子保险丝 TPS259824（U26）进行过流和欠压保

护 ： 欠 压 阈 值 设 置 为 9.6V （ VINuvlo=1.2*(R1+R2)/R2 ）， 电 流 阈 值 限 制 为 6A

（Rilim=1460/(Ilim-0.11)），保护电路同时输出电源良好信号 PG。保护后的 VCC12V0 再经

多路 DC-DC 转换为板内各电源轨，整体电源架构如下图所示：
