2. 根因与修复（fix9r1 板测 FAIL → fix9r2）
--------------------------------------------------------------------------------
根因: 接收端只在捕获窗口的前 4096 样本内搜 ZC 训练帧，而 TX 是 59904 复采样
      CYCLIC 循环 burst，RX 捕获起点相对循环帧任意 → 前导落在前 4096 样本的概率
      ≈ 6.8%，其余 ~93% 锁到噪声（实测 training_corr_avg=0.110172 与噪声锁期望
      0.127 吻合）→ valid=1 假有效 → training_corr<0.9 → RF_DISTORTS_IQ 46/46，
      scored=0。
修复: fix9r2 改搜索不改 RF 数学 —— 显式循环帧布局 + 捕获 ≥2 周期 + 全周期搜索；
      逐文件从已知 ZC 训练帧恢复 gain/phase/timing/CFO/SRO/drift（共用核心
      iq_rf_sync_recovery.hpp，fix10 直接复用）；typed valid 语义（estimate_computed
      vs estimate_valid + 11 值 Failure 枚举 + failure token）；TX 帧验证器 + iio
      push 字节溯源 fail-closed；SRO 残差用与注入端一致的线性插值模型建模（修正
      相位-only SRO 无法抵消幅度损失的缺陷）。
