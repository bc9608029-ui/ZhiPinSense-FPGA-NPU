# Blind RX Sampling Contract — fix10class24-dualsdr-blind-clean1

Token: `M29-RML24-FIX10CLASS24-DUALSDR-BLIND-CLEAN1-SAMPLING-CONTRACT`

This document is the frozen authority for the **blind** (no-sample-prior) dual-SDR
pure-modulation RF classification test. It answers two questions the task asks to be
frozen **before** implementation (Phase A/B):

1. **What may the receiver use?** (the RX info boundary)
2. **What is the exact sampling / preprocessing contract?** (frozen, same for every class)

The receiver must classify 24 clean RadioML2018.01A waveforms that were generated by a
**pure modulator** (no training frame, no preamble, no tail, no canonical burst) and sent
over the air as RF — using **only** the received IQ and the frozen BF16 model. The
receiver never sees the transmitted sample, its DC, its scale, its window, or its label.

---

## 1. RX information boundary

**The receiver MAY use:**

| Input | Notes |
|---|---|
| Received IQ | RX capture only (the 2048-complex contiguous block) |
| Frozen BF16 model | json `28272abc…`, raw `c1781aec…`, ckpt `96cd25f8` |
| Common RX config | LO / sample-rate / BW / gain — fixed for ALL samples |
| Frozen reconstruction scale | `rx_scale` — the same number for every class |
| Frozen window rule | offset + length — the same for every class |
| Anonymous `run_id` | `session_id` + `run_nonce`; correlates records only |

**The receiver MUST NOT read:**

- the source sample / reference IQ;
- DC / AC-RMS / TX-scale / any sidecar value;
- the class, the baseline prediction, or the `source_index → class` mapping;
- the correct start point / model window beyond the frozen rule;
- the TX waveform template.

`run_id` is **anonymous**: it must not encode the class and never enters the DSP path
(used only to correlate the board's records with the PC's TX record at judging time).
The labels are read **only** by the offline judger.

## 2. Sampling / preprocessing contract (frozen, identical for all classes)

### 2.1 Model input contract

The frozen model input is `[2, 1024] float32` little-endian (8192 bytes): row 0 = real,
row 1 = imag, i.e. `np.ascontiguousarray(X.T)` of the RadioML frame. The clean-IQ domain
is the model's expected input with **no re-scaling** (per-class `TARGET_RMS`).

### 2.2 TX → CI16 → reconstruction chain

1. `generate_class(name, seed)` returns a clean complex frame `x` (1024,) at the class's
   `TARGET_RMS` (the model's expected domain).
2. The PC quantizes to CI16 with **half-away-from-zero** rounding (`lround`, NOT
   `rint`/round-half-to-even — byte-exact red line):
   `X_iq = lround(x * tx_scale)`.
3. The board reconstructs with the **frozen** inverse scale (no per-sample estimation):
   `z[k] = int16_received[k] / adc_full_scale * rx_scale`, where
   `rx_scale = adc_full_scale / tx_scale`, so `z ≈ x` (quantization error ≈ −41 dB).

### 2.3 Frozen constants

| Name | Value |
|---|---|
| `adc_full_scale` | `2048.0` |
| `tx_scale` (S) | `117.84922023433009` |
| `rx_scale` (2048/S) | `17.37813789457223` |
| `tx_peak_target` | `1600.0` |
| `max_peak` (over the 24 production seeds) | `13.576670230134553` (AM-SSB-WC, seed `3000017`) |
| `max_lround_ci16_abs` | `1599` (< 2048, no clip; continuous peak = 1600, lround real/imag separately) |
| `seed_base` | `3000000` |
| `shuffle_seed` | `20261020` |
| `flush_complex` | `4096` |
| `capture_complex` | `2048` |
| `window_complex` | `1024` |
| `window_offset` | `512` |
| `measurements` | `25` (1 negative control + 24 waveforms) |
| sample rate / LO / BW / gain / atten | `2.56 Msps` / `2.4 GHz` / `18 MHz` / `35 dB` / `−40 dB` |

`tx_scale = 1600 / max_peak`. The 24 production seeds are `seed_base + class_index`
(`3000000 … 3000023`), so `max_peak` is the exact worst-case instantaneous peak the TX
will emit; `lround(x·S)` never exceeds `1600`, leaving 22 % headroom below the 12-bit
DAC full scale `2048`.

### 2.4 Frozen window rule (blind, no reference)

```
flush   4096 complex   (discard, settle the RX stream)
capture 2048 complex   (ONE contiguous RX refill)
window  samples [512, 1536)  == 1024 complex  ->  [2,1024] f32 tensor
```

The same rule is applied to every class; there is no window selection by reference-IQ
matching and no per-label branch. CFO/timing estimation is **explicitly out of scope**
for this blind test (documented `NA`).

### 2.5 Protocol (PC TX = server, board RX = client)

```
board -> PC: HELLO      {session_id, run_nonce, measurements, sample_rate, center_hz, rx_bw, flush, capture, window_offset}
PC   -> board: HELLO_ACK {session_id, run_nonce, measurements, ok}
board -> PC: TRANSMIT   {source_index}         (0 = negative control/TX-off, 1..24 = waveform ordinal)
PC   -> board: TX_READY {source_index, tx_active, file_sha256}   (tx_active MUST be false for source_index 0)
board        : flush + capture + window + reconstruct + infer x2 + raw24
board -> PC: CAPTURED   {source_index}
PC   -> board: CAPTURED_ACK {source_index}
... (repeat for all measurements)
board -> PC: STOP
PC   -> board: STOP_ACK
```

`source_index` is the **only** correlation key the board knows. The PC maps
`source_index → class` internally (recorded for the judger), but the class never crosses
the control channel toward the board.

---

## 3. What this test is NOT

- No training frame, no preamble, no tail, no canonical burst, no reference recovery.
- No per-class switching, no window selection, no sample-prior matching.
- No auto-repeat / fusion / 480-frame extension: exactly one measurement per waveform.
- The board **never** forces a classification; a non-finite or infra-failed sample is
  recorded as such and stays in the denominator.
