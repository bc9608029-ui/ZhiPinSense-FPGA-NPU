# 五页 UI 详细审查与 UI2 收口

## 结论

UI2 以 1280×720、7 英寸触摸屏、软件帧缓冲为约束完成电脑侧收口。设计目标不是堆装饰，而是在现场一眼看懂、触控可靠、数据口径诚实。

## 页面结构

1. `CLASSIFY`：Top-1 为主视觉，Top-2/3 为次级证据。
2. `MEASURE`：三张主指标卡 + 频谱估算与接收配置两组详情。
3. `WATERFALL`：保持已经验证的频谱瀑布布局。
4. `CONSTELLATION`：256 个恢复 IQ 显示点，使用独立显示缩放，不改变模型输入。
5. `TUNING`：定频/扫频两种模式、四个频率字段、启动/停止、应用状态和命令反馈。

## 参数真实性

直接计算并展示：

- 模型置信度；
- 恢复后 IQ 的 RMS、峰值与 PAPR；
- 相对峰值频谱中位数、峰值突出度；
- 基于固定 `-20 dB rel` 阈值的活动 bin 数和占用带宽估计；
- 功率加权频谱中心偏移估计；
- 中心频率、采样率与 RX 增益设置值。

明确不展示：

- 未做 ADC 标定时的 dBFS；
- 未做噪声专门估计时的 SNR；
- 把模型归一化幅度当物理功率；
- 把模型置信度当实际准确率。

## 视觉与触控修正

- 参数页由四个密集小表格改成三张主指标卡和两个平衡详情卡。
- 全页底部信息条改为有真实来源的信号状态、RX 增益设置、帧号、来源和模型身份，不再长期显示 `SNR -- / LATENCY --`。
- 第五页详细状态改为左右两栏，避免右半屏大面积空白。
- 导航标签 `SETUP` 改为更明确的 `TUNING`。
- 键盘起始位置从 y=86 下移到 y=142，消除与标题/当前值重叠。
- 键高 82 原始像素，仍超过目标触控尺寸。
- 离开第五页自动取消未提交编辑，防止隐藏模态状态吞掉后续触摸。
- 继续使用深色、扁平、高对比语义色；不引入阴影、模糊、渐变或高开销动画。

## 离线证据

- `test_ui_measurements.py`：确定性复数单音验证测量生成与空数据 fail-closed。
- `static_audit.py`：16/16，通过测量接线、无伪 SNR/dBFS、EST 标签、键盘几何和五页导航审计。
- 扫描策略与控制协议原回归仍通过。
