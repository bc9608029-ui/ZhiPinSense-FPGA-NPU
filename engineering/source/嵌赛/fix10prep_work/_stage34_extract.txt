## 5. FakeRfLink 数据流

```
FakeTxDevice.tx_start_cyclic(burst)  ──► link.publish_tx(tx_uri, burst)   [写真实 DMA 波形, tx_running=true]
FakeTxDevice.tx_stop()               ──► link.stop_tx(tx_uri)             [tx_running=false]
FakeRxDevice.read_rx(n)              ──► link.read_rx(rx_uri, n)
                                          ├─ tx_running==false → 只回噪声(noise_rms)
                                          └─ tx_running==true  → 读真实 DMA 波形
                                             → 施加 timing_offset → gain/phase
                                             → CFO(cfo_hz 逐采样去旋) → SRO(sro_ppm 重采样)
                                             → + noise_rms 高斯
```
计数器（测试断言）：`tx_fake.tx_start_count>0`、`tx_fake.main_rx_samples_requested==0`、`rx_fake.tx_start_count==0`、`rx_fake.main_rx_samples_requested>0`；link 校验 `rx_uri==tx_uri` → fail-closed（发现 URI 交换）；禁止单实例内部 echo、禁止直接塞 expected payload、禁止绕过真实 burst/DMA 格式/捕获流程。

## 6. guard 构造/析构顺序

- 成员声明顺序 `tx_guard_` 在 `rx_guard_` **之前**；构造顺序 `open tx_dev → open rx_dev → 构造 tx_guard → 构造 rx_guard → 配置`。
- **`rx_guard` 构造失败（如 `save_params` 抛）→ C++ 按声明逆序析构已构造成员 → `tx_guard_` 析构 → `restore()`，TX 自动恢复**。
- 异常路径：`tx_guard` 析构前先 `tx_stop()` + 销毁 TX buffer（DualSdrSession 析构顺序：先停 TX 会话/销毁 buffer，再两 guard restore）。
- 正常/异常都分别恢复两设备，结果含 `tx_restore_ok`/`rx_restore_ok`，任一 false → 整门 FAIL。

## 10. clean 双 SDR 复用同一 CI16 的证明方法

不重新生成第二批。证明 = **运行时 SHA 恒等断言（fail-closed）**：
1. clean manifest 记录每文件 `sha256`（生成器产物）。
2. 路径 B（数字 baseline）读文件 → 校验 `sha256_file == manifest.sha256` → 预处理 → 推理 → 写 baseline TSV（同一 `sha256` 列）。
3. 路径 C（双 SDR）`transfer_one_file_dual_sdr_fix10` 加载同一文件 → `r.tx_sha_pre`（缩放前 payload SHA，`verify_loaded_tx` 计算）→ **断言 `r.tx_sha_pre == manifest.sha256`**，不一致即 throw。
4. 故 `数字baseline文件SHA == 双SDR发送文件SHA` 由单一批文件 + 双重 SHA 校验强制，非靠约定。
