# 燕尾滑盖 v1

原文件 `外壳.f3d`、`外壳1.stl` 保留。参数化修改以 `dovetail_lid_v1.scad` 为源；这是基于STL的派生模型，没有伪称修改Fusion原生特征树。

主体外形316×150×196 mm，壁厚3.5 mm。两条长边内侧增加10 mm宽导轨；从X负方向短边滑入，X正方向保留端墙限位。两条槽口会修改入口短边顶部，其他开口保持。

盖厚3 mm，装好后顶部约199.35 mm；燕尾深入顶部6 mm。内部器件在顶部188–196 mm及导轨占用区不得干涉。新增导轨占用Y约3–13、137–147 mm；必须实物复核。

先打印40 mm长的fit_body、fit_lid试配。默认间隙0.35 mm，属于待打印验证值，不是已验证公差。盖子沿长方向抽出，需要约316 mm操作空间。

盖板为平面朝下、燕尾朝上打印，无需给燕尾底部加支撑。主体建议保留原打印方向，检查导轨悬挑支撑；STL无需因坐标有负值而改尺寸。

v1依靠滑动配合保持，带末端限位，没有锁紧机构；携带前需确认不会滑出。若需要锁紧，可下一版加弹性卡点或独立止退件，不能把当前盖子宣称抗跌落。

当前保留中央两组散热槽；未开RX孔，因为接口位置和孔径尚未给出。RX最终固定位置决定后再开孔，不能凭空选孔。顶部电缆必须留抽盖行程或采用可拆连接。

打印整件前确认打印机能容纳316×150 mm，常见小平台需分件方案；不要直接缩放，否则配合失效。
