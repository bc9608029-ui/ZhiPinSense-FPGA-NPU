# 五页 UI 视觉规范

## 风格

采用深色科学仪器风格，避免游戏化霓虹和大面积渐变。背景、卡片、边框、主文字、次文字、交互、成功、警告、错误均使用语义色；颜色不单独承载状态。

## 层级

- Top 1：页面最大字号，类别和置信度并列。
- Top 2/3：同一列表、较小字号，不使用多个抢眼色。
- 页面标题、工作模式、RUN/STOP 和锁定状态始终固定位置。
- 频率优先用 MHz 显示 4–6 位小数，底层仍保留整数 Hz。

## 五页

1. CLASSIFY：定频 Top 3；扫频发现列表，选中项展开 Top 3。
2. MEASURE：分为频率/同步、信号电平、处理性能三组；不显示未校准 dBm。
3. WATERFALL：固定色标；显示频率刻度、当前 LO、锁定标记和扫描进度。
4. CONSTELLATION：保持等比例坐标，只画当前选中信号；失锁时标历史快照。
5. SETUP：模式、频率输入、开始/停止；危险或无效输入给出明确原因。

## 7 英寸触控约束

- 触控目标最小约 44×44 px。
- 正文不小于约 18–20 px；关键信息 28–40 px。
- 同屏主要动作不超过 3 个。
- 交互后 400 ms 内反馈；扫描超过 1 秒显示进度，超过 10 秒显示当前频点和取消按钮。
- 中文标签应短、直白；必要时保留 RF、CFO、RMS 等行业缩写。

## 扫频信息诚实性

- “Top 3”表示同一个信号的模型前三概率。
- “发现列表”表示多个频率条目或历史发现。
- 不将不同 LO 的采样片段绘成看似连续的实时瀑布。
- 不将多个信号的 IQ 叠加成一张星座图。
