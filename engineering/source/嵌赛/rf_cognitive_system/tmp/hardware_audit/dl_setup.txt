4. Win 系统运行 1_scripts 目录下脚本常见报错

4.1 ultralytics 版本相关


由于 ultralytics 版本更新较快，modelzoo yolo 系列模型的工程文件夹中通常有一个 ultralytics

文件夹，python 环境中也会安装一个 ultralytics 包，二者会存在版本不一致，如果没有指定

调用当前目录的 ultralytics 文件夹，会优先调用 python 环境中地 ultralytics。

Torch_v2.0.1 环境安装的是 8.4.5 版本




                                   10
yolov8_icraft 目录下的是 8.0.199 版本




运行 python 1_save.py 报错：AssertionError: 0.0 MB output model size




从报错可以看出调用的是 torch_v2.0.1 环境下的 ultralytics，该情况下可以尝试指定优先调用

本地文件夹的 ultralytics。

在脚本中增加 sys.path.insert(0,R"..")，把当前目录的上一级目录加入到 Python 模块搜索路

径的最优先级。




以下问题，解决方式：在脚本中增加 sys.path.insert(0,R"..")
