# 任务书：fix10class24-dualsdr1 — BF16 原始24类 NPU直注与双SDR测试准备

## 1. 目标

在当前 fix10prep3 双 SDR 物理链路基础上，建立独立的 24 原始调制类实验路径：

1. 使用已编译的全网络 BF16 24输出模型。
2. 保持 AM-SSB-WC 与 AM-SSB-SC 为两个独立类别，不执行24→23合并。
3. 准备24类板端 NPU 数字直注测试。
4. 准备24类 PC-TX → 同轴 → 板RX → 恢复 → NPU 双SDR测试。
5. 每个原始类别固定一个样本，共24个样本。
6. 完成全部离线代码、测试、确定性打包和用户执行命令。
7. API 禁止操作板卡和 SDR；所有板测由用户执行。

本任务不替换现有23类系统。23类合并模式仍是稳定主路径；24类 BF16 是独立、可选择的实验模式。

———

- 当前 fix10prep3 的 BPSK+4ASK 23类双SDR烟测通过；
- scored=2

## 12. 构建与板端资源准备

板端内存约1GB，构建任务必须显式防止OOM。

AUDIT中写入：

if [ -f /swapfile_fix10prep2 ]; then
    swapon /swapfile_fix10prep2 2>/dev/null || true
fi

swapon --show
free -h

export LIBIIO_ROOT=/opt/sdr/libiio-0.26

优先支持：

BUILD_JOBS=1 bash scripts/build_on_board.sh

如果现有脚本不支持BUILD_JOBS，允许仅对构建脚本做兼容性修改：

JOBS="${BUILD_JOBS:-$(nproc)}"
make -j"$JOBS"

默认发布命令使用：

BUILD_JOBS=1

不得通过增大并行度缩短构建时间。
