4.13
USB 接口
悟净Lite 开发板上有4 个USB2.0 HOST 接口，USB2.0 收发器采用的是一个1.8V 的，
高速的支持ULPI 标准接口的USB3320C-EZK 芯片，再通过一个USB HUB 芯片USB2514 扩展出
4 路USB HOST 接口。PSOC 的USB 总线接口和USB3320C-EZK 收发器相连接，实现高速的
USB2.0Host 模式的数据通信。USB3320C 的USB 的数据和控制信号连接到PSOC 芯片PS 端的
BANK501 的IO 口上，USB 接口差分信号(DP/DM)连接到USB2514 芯片扩展出4 个USB 接口。
2 个24MHz 的晶振为分别为USB3320C 和USB2514 芯片提供时钟。4 个USB 接口为扁型USB
接口(USB Type A)，方便用户同时连接不同的USB Slave 外设(比如USB 鼠标和USB 键
盘），每个USB 接口提供了+5V 的电源。

4.16
HDMI 输出接口
HDMI 输出采用了IO 模HDMI 信号，输出可以达到720P@60HZ 高清传输。实测1080P@60HZ
的信号输出，有的显示器会存在闪屏的情况。因为在运行1080P@60HZ 的时候，HR 的bank
的时钟运行在748.5M 的TMDS 速率，超出了手册HR 的bank 的IO 的最高710M 的速率要求。

4.17
SDI 接口
悟净Lite 开发板支持两路SDI 输入接口。
LMH0344 自适应电缆均衡器设计用于均衡通过电缆（或具有类似色散损耗特性的任何介
质）传输的3-Gbps、HD-SD 的SDI 数据。均衡器工作在从125 Mbps 到2.97 Gbps 的宽数据
速率范围内，支持ST424、ST292、ST344 和ST259。

4.20
XADC
JFMQL30TAI676H 片内集成了一路12bit、1MSPS 的XADC 模数转换器。悟净Lite 开发板
共引出了5 路XADC 接口：1 路专用模拟输入VP/VN（接口J24），2 路外部辅助模拟输入

VCC1V5 分压至0.75V、VAUX9 通道将VCC1V8 分压至0.9V 后送入XADC，实现片内电源监测。

4.21
电源管理
