# 双 Pluto 一 TX 一 RX 的数字域多载波合成与频谱审计（任务 4）

实现：`src/tx_synth.py`（合成）、`src/spectrum_audit.py`（审计）。
全部离线，不发射。

## 场景约束（诚实边界）

一 TX 一 RX 时，只能在一个 TX 瞬时带宽内（±0.45×fs = ±1 152 000 Hz，即
2 304 000 Hz 跨度）用**数字域频移后求和**的方式同时呈现多个公共帧载荷。
以下情形**需要额外硬件**，不能用快速轮流发射冒充“同时”：

- 目标落在不同调谐频段（超出单个 TX 瞬时带宽）；
- 目标总带宽或载波数使峰均比超出 DAC 削顶预算。

本线只交付波形生成 + 频谱审计，**不自动换硬件**。

## 合成模型

- 每个载波 = 同一公共帧（单位 RMS 替身）乘以 `exp(j2π·offset_hz·t)`，再按
  `amplitude` 加权求和（`tx_synth.synthesize`）。
- 公共帧替身：QPSK 符号经 ZOH + 4 抽头平滑，符号率可配（默认 8 kHz →
  占用带宽约 8 kHz），单位 RMS（`make_common_frame`）。
- 输出用 `to_int16_clipped` 归一到 int16 满刻度 ±30000 并封顶。
- **已核验（2026-10-29）**：真实公共前导/尾是**满带宽 QPSK**（−20 dB 占用带宽
  ≈ 1.00×fs，99% 功率带宽 0.92–0.95×fs），**不是 ≤10 kHz 窄带替身**
  （见 `docs/OCCUPIED_BW_VERIFICATION.md`）。因此本文件的窄带替身
  （`MAX_CARRIER_OCCUPIED_BW_HZ` 默认 8 kHz 符号率）**只代表一个假设的窄带
  载波，不代表真实公共帧**；真实公共帧多载波在同一 dwell 内频谱几乎完全重叠，
  分离靠 `detect_public_training` 的 despread-FFT 按 CFO 分离，不靠带宽间隙。

## 审计项（`spectrum_audit.run_audit`）

| 项 | 含义 | 离线口径（待板测验证） |
|----|------|----------|
| 采样带宽 | 载波 offset 必须落在 ±1 152 000 Hz | `TxCarrier` 构造期拒绝越界 |
| 峰均比 PAPR | 合成信号的峰值/RMS；多载波 PAPR 随载波数增长 | `papr_db` |
| 削顶分数 | 以 12 dB DAC 余量归一后超满刻度的样本占比 | `clip_fraction`，余量 `TX_HEADROOM_DB=12` |
| 保护带 | 相邻载波最小间距 ≥ 12 500 Hz（离线测试目标，待板测验证） | `min_guard_hz` / `guard_ok` |
| 互调 IM3 | 三次无记忆非线性 `c·|x|²x` 的 IM3 相对载波电平 | `im3_relative_db < 0` |
| 公共前导互扰 | 其它载波在该载波占用带内的谱泄漏（同前导但异频 → 纯泄漏） | `leakage_from_others_db` |

## 已覆盖测试

见 `tests/test_tx_synth.py`、`tests/test_spectrum_audit.py`：单位 RMS、求和、
int16 封顶、越界拒绝、帧长一致性、保护带合规/违规、互调负、串扰 < −20 dB、
PAPR 随载波数增长。

## 诚实结论

- 在单 TX 瞬时带宽内、**假设的窄带替身载波**占用带宽 ≤10 kHz、间距 ≥12.5 kHz
  （12.5 kHz 为离线测试目标，待板测验证）、载波数受 PAPR 预算约束时，数字域
  多载波合成在离线层面成立（审计全过）。
- **注意**：该窄带替身**不代表真实公共帧**（真实公共前导/尾已核验为满带宽
  QPSK）。真实公共帧的频域几乎完全重叠，多载波间隔/共存包络不能套用窄带口径；
  真实载荷占用带宽、真实 DAC 非线性、真实收发隔离仍需板端实测。
