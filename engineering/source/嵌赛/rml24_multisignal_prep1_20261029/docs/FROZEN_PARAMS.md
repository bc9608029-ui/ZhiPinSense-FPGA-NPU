## 1. 频率与采样（合同 §3，冻结，2026-10-29 修订）

| 参数 | 值 | 依据 |
|------|-----|------|
| `sample_rate_hz` | 2 560 000 | 合同 §3 |
| `fft_length` | 1024 | 合同 §3 |
| `bin_hz` | 2500 | 2560000/1024（物理事实） |
| 默认步长 | 1 000 000 | 现有 `scan_runtime` 默认 |
| 最大步长（跨度/上限） | **2 304 000** | 主链既有 `ScanConfig.validate` 值 `0.9*fs` |

**修订口径（收回旧表述）**：`2304000 = 0.9 * 2560000` 是**扫描跨度/上限**，
不是 `fs`，也不是 bin 对齐要求。调谐步长**不天然等于 2500 Hz 整数倍**——除非
真实接收器/控制器确有对齐前提（须核实并记录原因），否则**不设该限制**，频谱
拼接按实际整数 Hz 坐标完成。因此**不再要求**步长为 2500 的整数倍，也不再为
凑整数 bin 把主链改成 2302500；保留真实频率坐标 2304000。

## 4. 不承诺项（无证据不承诺）

1. **不承诺**任意重叠信号分离：频差 < 12 500 Hz 或近邻功率差 > 25 dB 的情形
   不承诺分离（12 500 Hz / 25 dB 本身是待板测验证的测试目标），可能合并或漏报，
   判分按“漏项计错”如实处理。
2. **不承诺**超出单 TX/RX 瞬时带宽的多信号同时呈现（需要额外硬件）。
3. **不承诺**以快速轮流发射冒充同时多信号。
4. **不承诺**目标列表时间戳代表同时识别（单 SDR 顺序扫描）。
5. ~~不承诺真实公共帧占用带宽~~：**已离线核验**——真实公共前导/尾是满带宽
   QPSK（每样本一个独立符号、无脉冲成形 → −20 dB 占用带宽 ≈ 1.00×fs，
   见 `docs/OCCUPIED_BW_VERIFICATION.md`），**不是 ≤10 kHz 窄带**。离线 TX 合成
   的窄带替身（`src/tx_synth.py`）只是控制面自测工具，**不代表真实公共帧**。
   仍待板测的是真实**载荷**波形占用带宽（数据集 1024 复样本定义，不在本树）。

## 5. 目标记录（合同 §7，冻结九字段）

`target_id, center_hz, bw_hz, power_valid, top3, confidence, last_seen,
status, backend`。逐字段语义见 `contract/target_record_schema.json`。
记录本身不新增字段；频谱坐标/调谐时间/真实后端等诊断放在独立的扫描日志
（`src/ui_model.SpectrumFrame`），不污染冻结记录。

**power_valid 数值契约（本线补）**：该字段是**数值功率**，不是裸 bool 标志。
- 来源：检出 PSD 峰值功率 − 该 dwell 的自适应中位噪声底（即所选峰的 prominence）。
- 单位：dB，相对该 dwell 自适应中位噪声底（**相对尺度**，不是 dBm、不是 dBFS）。
- 有效范围：[14, 80] dB；≥14 dB 即有效检出（检出器只报 ≥ 中位+14 dB 的峰），
  NaN/缺失 = 未测/无效。
- 红线：离线无量值溯源契约，**不得从此字段标 dBm**。
