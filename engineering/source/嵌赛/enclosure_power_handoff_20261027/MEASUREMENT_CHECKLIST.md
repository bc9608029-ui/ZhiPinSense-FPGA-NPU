# 外壳定稿前实测清单

所有尺寸单位为 mm。每项同时保存带尺照片，记录测量日期和测量人。

## 主板

- [ ] 外形长、宽、总高。
- [ ] 四个安装孔直径及相对同一基准角的 X/Y。
- [ ] 板底突出件高度和所需支柱高度。
- [ ] 风扇外形、中心位置、进/出风方向。
- [ ] 电源、HDMI、USB、网口、串口的插头包络和拔插空间。
- [ ] HDMI 拨动开关位置及手指操作包络。

## 屏幕

- [ ] 整机外形复核。
- [ ] 可视区宽高及相对外框偏移。
- [ ] 固定孔/卡扣/背胶区域。
- [ ] HDMI、电源、触摸 USB 接口位置和插头包络。
- [ ] 正面板倾角与观看高度。

## SDR 与射频

- [ ] Pluto 带壳长宽高。
- [ ] USB 端插头长度和自然弯曲半径。
- [ ] RX SMA 延长线长度、两端接头直径和弯曲半径。
- [ ] SMA 面板座开孔、螺母和扳手空间。
- [ ] SDR 固定方式和散热间隙。

## 适配器与低压供电

- [ ] 12 V 适配器外形复核。
- [ ] 品字输入端外轮廓、插头轮廓、插拔行程。
- [ ] 输出线出口、弯曲半径和应力释放。
- [ ] 降压模块型号、外形、安装孔、输入输出额定值和温升。
- [ ] 屏幕实际最大电流与主板实际最大功耗。
- [ ] 适配器与 SDR/主板/信号线的隔离距离。

## 打印与装配

- [ ] 打印机有效 X/Y/Z。
- [ ] 材料与热环境。
- [ ] M3 自攻或热熔螺母选择。
- [ ] 螺丝刀装配路径。
- [ ] 中间层拆装顺序。
- [ ] 底脚、防滑、提手或搬运位置。
