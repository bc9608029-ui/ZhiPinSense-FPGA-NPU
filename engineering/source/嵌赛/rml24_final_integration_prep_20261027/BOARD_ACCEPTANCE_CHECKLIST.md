# 最终上板验收清单

## A. 安装前

- [ ] 电脑侧输入自检全部 PASS。
- [ ] 当前 SD 启动分区、systemd 单元和 `/opt/rml24-system` 已备份。
- [ ] 原 Stage7 定频系统仍可启动。
- [ ] 候选安装到独立目录，没有覆盖原目录。

## B. 手工候选测试

- [ ] 同一时刻只有一个 RX/NPU 进程和一个 UI 进程。
- [ ] FIXED 模式能完成 24 类识别。
- [ ] BAND_SCAN 能发现、物理居中并锁定两个测试频点。
- [ ] 低→高→低跳频均发生丢锁重扫，且重新锁定。
- [ ] 停止发射后显示“无有效信号”，没有伪分类。
- [ ] STOP 后允许在途帧结束，但计数随后保持不变；START 后恢复。
- [ ] 四页 UI、触摸导航、频谱、瀑布、星座均更新。
- [ ] 当前频率、模式、锁定状态和置信度可见。

## C. 最终独立集

- [ ] manifest 在运行前冻结并记录 SHA256。
- [ ] 板端不存在真值文件或私有频率计划。
- [ ] 三个 240 帧测试均无缺失序号。
- [ ] 定频准确率达到预先确定的门槛。
- [ ] 两个扫频频点分别达到预先确定的门槛。
- [ ] 混淆矩阵和全部错误样本已保存，没有剔除。

## D. 正式部署

- [ ] 修改 systemd 前已记录旧 ExecStart。
- [ ] 新服务使用绝对路径并设置单实例保护。
- [ ] 服务失败不会循环占用 NPU 或显示设备。
- [ ] 软件重启后 UI 与 RX 自动启动。
- [ ] 物理断电再上电后 UI 与 RX 自动启动。
- [ ] PC 发射端断开时系统保持可操作且不伪分类。
- [ ] 回退到旧 Stage7 的命令已经实测。

## E. 稳定性与现场

- [ ] 连续运行时间已记录；期间无崩溃、内存持续增长或显示冻结。
- [ ] HDMI、USB、SDR、同轴线和供电全部固定并编号。
- [ ] 完整演示可在不登录板端、不手工敲命令的情况下完成。
- [ ] 断电重启到可操作界面的时间已测量。
- [ ] 演示失败时有 2 分钟内可执行的恢复方案。

全部勾选前，不得写 `PROJECT_COMPLETE` 或“最终比赛版本已通过”。
