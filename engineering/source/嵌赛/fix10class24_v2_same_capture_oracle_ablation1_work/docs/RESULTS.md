## 4. 关键发现

1. **O1（只改窗）无增益**：agree/NRMSE 两会话均不变（fix2 2→2、old 1→1）。fix2 的
   frac_delay 已修正分数定时，循环窗无残余整数错位 → **H1 不支持**。
2. **O2（只改尺度）几乎无增益**：fix2 2→2、old 1→2 → **H2 非主要**。
3. **O3（只改直流）是最大单项修正**：fix2 agree 2→5、label 2→6、NRMSE 3.61→0.76（虚假
   LO 直流是 O0 残差中最可修正的单一项，印证 fix3 的「1/|a|≈32 直流放大」）。但仅到
   5/24，远低于 23/24 → **H3 次要贡献**（最大单因子，但非主导）。
4. **O4（组合）反低于 O3**：fix2 4 < O3 的 5。联合尺度+直流 in-sample 拟合把尺度拟合
   噪声引入，翻转一帧，说明尺度并非稳定可估的常数 → 与「时变」一致。
5. **O5（真正交叉验证仿射）上界 fix2=5/24、old=2/24**，远低于数字基线 23/24：即使把
   窗+尺度+直流+广线性全部交给 oracle 最优仿射（且严格交叉验证、无 in-sample 泄漏），
   仍有 18–19/24 帧无法修到数字基线 → **H4（固定仿射修正不足）支持**。
6. **数字基线 23/24 只证模型对数字 v2 域健康**，不能排除模型对真实 RF 残余失真失效 →
   **H5（模型 RF 域失配）未决，不可排除**（与 H4 可同时成立）。

## 5. 训练段 vs 载荷段残差缺口

生产 `training_residual_rel` 0.086–0.107（fix2，训练块）过门，但载荷窗 oracle 修正后
NRMSE 仍 0.6–1.2（fix2/old）。训练（边沿参考）拟合良好、载荷（内部）拟合差，且这一
差距**不能用**「~6× 门」表述（二者归一化与段不同，不可直接比较）；只能说载荷内无导频、
其残余失真不能由前导/训练块边沿参考唯一恢复。
