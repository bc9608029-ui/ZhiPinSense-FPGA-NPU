# RML24 最终作品主交接（2026-10-27）

## 当前基线

- 定频历史最佳：475/480 = 98.96%。
- 当前固定链回归：464/480 = 96.67%。
- 居中扫频两个频点：472/480 = 98.33%。
- 公共帧 two-DC 恢复与冻结 BF16 模型是当前有效识别基线，不得回退到早期逐样本真值补偿。

## 四个电脑侧交付

1. `enclosure_power_handoff_20261027.zip`：外壳、结构、供电。
2. `rml24_ui_fivepage_prep_20261027.zip`：五页 UI 候选与频率控制合同。
3. `rml24_final_integration_prep_20261027.zip`：最终集成、验收、演示脚本和证据索引。
4. `rml24_fpga_feature_migration_prep_20261027.zip`：Power/Lag/Energy/Peak 最小风险 FPGA 迁移准备。

## 推荐执行顺序

1. 保全当前可工作的位流、板端树和 RF 结果；做完整备份。
2. 在独立 Procise 工程综合并验证 FPGA 特征侧路，软件路径保持默认。
3. 上板同帧 A/B，确认特征 bit-exact、模型输入 SHA 和预测不变。
4. 合入五页 UI；补数字键盘、扫频发现列表和后端状态显示。
5. 回归定频与扫频；验证软件回退、断电启动和连续运行。
6. 最后做外壳装配、指标表、演示视频和答辩材料。

## 功能边界

- 第 1 页识别：定频 Top3；扫频显示多个候选信号。
- 第 2 页参数：中心频率、功率/RMS/Peak、CFO、质量、后端及延迟；只显示经过校准验证的量。
- 第 3 页瀑布；第 4 页星座；第 5 页固定/扫频模式与频率输入。
- FPGA 先迁移确定性低风险特征；FPGA FFT/智能扫频属于下一阶段，不能与首轮迁移同时冒险。
