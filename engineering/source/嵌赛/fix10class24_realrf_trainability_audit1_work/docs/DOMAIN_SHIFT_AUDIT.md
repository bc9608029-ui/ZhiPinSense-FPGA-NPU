## 2. Q1：真实 RF 恢复后 IQ 是否保留类别信息？

**部分保留（PARTIAL）。** 强制分类（旁路 0.100 门，仍用冻结模型）在 full24 上得到
**18/24 = 75%**，远超随机 1/24（4.2%）与当前 e2e 门控 10/24。说明 RF 恢复后 IQ 仍携带
可观的类别信息，未完全破坏；但低于数字域 95.8%，说明 RF 链路引入了信息损失。

## 3. Q2：1/24 是模型域不匹配还是信息被破坏？

**接收链残差瓶颈（RECEIVE_CHAIN_RESIDUAL_BOTTLENECK），不是纯模型域不匹配。**

- 模型在 A 域 87.3%、B 域（数字）95.8%——模型本身健康，无需为分类能力重训。
- C 域恢复残差中位 **0.113**，正好压在 0.100 门之上（`rf_fix2_target` 0.086–0.107、
  `rf_independent_v2` 0.113–0.667），导致门拒大量帧（`rf_independent_v2` 门 0/24）。
- 门拒/低门内精度是**恢复残差越过门限**造成的，不是模型对 RF 域的无能为力：强制分类
  仍能到 75%。

因此 1/24（e2e）主要是「恢复残差 > 0.100 门 → 门拒 → e2e 归零」的**接收链门控
产物**，而非「模型在新域彻底失效」或「信息被彻底破坏」。

## 4. 结论

瓶颈在接收链（恢复残差 0.10–0.16 系统性越过 0.100 门），不在模型。修接收链优先于
任何训练。
