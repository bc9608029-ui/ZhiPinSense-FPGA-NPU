# M29-RML24-REALRF-TRAINABILITY-AUDIT1 — 局限

状态：`…-LIMITATIONS-COMPLETE`

## 1. 本审计能确定什么

- 冻结 BF16 模型在原始域（A）与数字恢复域（B）健康，在真实 RF 恢复域（C）被接收链
  残差门控拉低到 e2e 2.1%–41.7%。
- RF 恢复后 IQ **部分**保留类别信息（强制分类 18/24 = 75%）。
- 当前数据不足以最终微调（2 会话 × 24 重复源波形，无法会话级切分）。

## 2. 本审计不能确定什么

- **不能**确定 RF 链路「具体哪个物理环节」造成残差 0.10–0.16（LO 泄漏 / 非线性 /
  时变 / IQ 不平衡的相对占比未在本任务定量）；这需要 RF 域诊断（另立任务）。
- **不能**确定「修接收链后模型在 RF 域能达到多少精度」——需要修链 + 新采集才能测。
- **不能**据此声称微调一定无益或一定有益——微调被红线与数据不足阻断，未实证。
- **不能**把「1/24 e2e」等同于「模型在 RF 域只有 1/24 能力」——强制分类 75% 证明
  该读数主要是门控产物。
- C 域未知/未标定 SNR，不与 A 域逐 SNR 匹配，不做逐 SNR 域对比。

## 3. 数据固有局限

- 每类只有 1 个源波形（tx_package 集合），无可用于类内方差估计的多实现。
- 真实 RF 仅 2 个 tx_package 会话 + 1 个 full24 会话，样本量远低于最终微调门槛。
- 数字与 RF 会话使用不同恢复链（fix2 vs independent_v2），B↔C 差异含恢复链差异成分，
  不只 RF 成分。
