# 第一项独立复核：ac-input-detailed-audit1

结论：NEEDS_CORRECTION。输入与已保存特征有复算依据，但计算实现存在缺陷，主要科学结论超出了实际分析。不能据此排除 A↔C 域差异，也不能认定误分类根因为“近分布内小摄动 × 决策边界敏感度”。

范围：仅第一项 A↔C 直接特征审计；未审查其他任务。只读检查输入、代码、结果；未修改原分析代码、模型、恢复器或门限，未碰板、SDR、训练。本文为新增独立复核记录。

## 已核实的有效部分

- C：58个文件，8192字节/[2,1024]，当前文件 SHA 与 inventory 全部相符。58×50=2900个保存特征按现有实现复算，无不一致。注意：同一实现复算一致不代表公式正确，也不是板端原始 SHA 的独立认证。
- C 实际为22类、22个 source_index；QPSK/8PSK没有张量。全部58个特征记录均为 DIAGNOSTIC_BYPASS，不代表门内或全部 RF 捕获的无偏样本。

- 未对21GB HDF5重新计算全文件 SHA；其身份仍沿用原审计声明的冻结 SHA 与 size/mtime 核验，不扩张成重新全哈希认证。

## P1：结论与统计证据不相称

### 1. 未执行相关性/区分能力检验，却输出“50项无一与错误相关”

位置：原工作树 scripts/run_ac_audit.py:311、323、347、425、444、449；报告:15、19、85、86、119。

phase5把每类正确和错误捕获混在一起，对各指标计算跨四个 A SNR 层的最大绝对 z，再做类内排名。它并没有按对/错分别比较特征，更没有计算相关性、分类区分能力或不确定性。

phase6用错误类 top3 的并集与对照类 top3 的并集取交集，就写成“排名完全相同、没有类特定差异”。集合交集只能表示部分指标名重合；即使排名相同，也不能推出数值、方向、分布相同。

“0 of 50 metrics correlates ... the null itself is a measured result”是代码写入的固定解释句，不是对应统计检验的结果。4ASK对照本身也有1/3误分类，并非纯正确对照。

影响：必须撤回“没有相关特征”“排除类特定域差异”“已定性为边界敏感度”的硬结论。尚未找到原因，不等于已证明不存在相关差异。现有同源重复捕获太少，也不能靠补一个显著性检验直接证明因果。

### 2. 用64QAM局部结果概括所有类别，存在直接反例

位置：报告:13–19、46、49、52、54、63、117–120；run_ac_audit.py:396–415只对64QAM生成带宽/动态示例。

独立从缓存与 C 张量计算的“C类内中位数在对应 A SNR20 分布中的百分位”：

| 类别 | 连续带宽 | 幅度变化均值 | 相位增量标准差 |
|---|---:|---:|---:|
| 64QAM | 73% | 86% | 89% |
| 128QAM | **4%** | 43% | 30% |
| 256QAM | 68% | **98%** | 57% |

128QAM连续带宽 C=0.119986、A20中位数=0.127172。不能用64QAM的73%代表它；正确256QAM的幅度变化也不是全部落在5%–95%内。

这些反例不证明带宽导致误分类，但足以否定“全部差异都小、方向一致、均在参考分布内”的概括。单变量若各自接近参考，也不能直接推出联合特征或模型输入分布内。

### 3. “全部24类通用”和总体对比存在覆盖、选择与加权问题

位置：报告:13、14、46、117；run_ac_audit.py:384–402、432–438。

实际22类；每类主要只有1个源的重复捕获，GMSK只有1个张量。58份均来自诊断门旁路，不能推广到全24类和所有接收帧。

另外，C总体中位数来自22类不等数量捕获；_a_pool_med只合并9个焦点/对照类；flatness总体 C 中位数又直接对照 A 的64QAM分布计算 z。类别构成与重复权重不一致，不能把该数值当作“跨类通用偏移”的证明。

### 4. 谱峰/带外中位数不能作为真实或等效 SNR

位置：ac_common.py:249–251；报告:14、46、54、77、117。

实现是 FFT最高功率 bin / |f|>0.25区域功率中位数，不是带内信号总功率/噪声总功率。它受带外滤波、窗、谱泄漏和信号频谱形状影响。

可以描述“此统计量位于所选 A20/A30参考值之间”；不能据此赋予 C“真实SNR≈25”，也不能选择该假定SNR后证明 C 在分布内。报告前言称不假定 SNR，正文却作了该假定。

## P2：指标实现与测试缺陷

### 5. 复数自相关先取实部，违背文档的相关幅度定义

位置：ac_common.py:257–259；results/metric_definitions.md:42–43。

实现 abs(real(vdot(x[k:],x[:-k]))/energy)，文档需要 abs(vdot(...))/energy。

确定性反例：1024点、归一化频率0.25的单位复单音，lag1实现值4.57e-19，而复相关幅度应为0.9990234375。

当前58个 C 张量lag1两种定义差的中位数约2.99e-6，最大0.019042。这证明缺陷真实存在，但不应夸大成“当前全部指标或分类因此全错”。受影响指标包括各滞后相关幅度、阈值相关长度和相应图，需重算 A/C 后再评估影响。

### 6. 声称使用的谱平坦度 floor 实际未应用

位置：ac_common.py:214–216；results/metric_definitions.md:31–32。

代码仅算并输出 flatness_floor=1e-12*total，没有用于 P 的 log/均值计算；文档却称 actually used。该常数派生量还参与50指标排名，在AM-SSB对照进入top3。必须区分数值实现参数与信号特征，并使定义与实现一致。

### 7. 两个异常测试吞掉自己的失败断言

位置：selftest_ac_audit.py:50–54、131–135。

若loader不抛异常，测试主动 raise AssertionError，随后被同一 except AssertionError 捕获，仍算通过。因此两个尺寸异常断言不能验证其声明。当前loader本身有尺寸assert；发现的是测试漏检，不是已证实当前错误尺寸被接受。
