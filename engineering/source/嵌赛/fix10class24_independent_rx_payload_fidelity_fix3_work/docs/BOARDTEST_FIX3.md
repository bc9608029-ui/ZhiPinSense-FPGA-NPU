# Fix3 板测说明（BOARDTEST_FIX3）

任务：`M29-RML24-FIX10CLASS24-INDEPENDENT-RX-PAYLOAD-FIDELITY-FIX3`

---

## 0. 结论先行：本任务没有板测步骤

Fix3 是**纯离线审计任务**，本轮（FIX3-REVIEW-R1）为方法论更正版，结论收窄为：

**现有 M1–M4 静态/线性去直流候选，在完整重估恢复参数后，只能把端到端准确率从 1/24 提升到 2/24（额外恢复被门拒的 AM-SSB-WC 帧），无法恢复 24 类准确率；尚未穷尽与类别无关、无需训练的完整恢复方案，也尚未证明必须微调。**

因此**没有**生产补丁可上板、没有可固化的新恢复链、没有可回传的新 `$OUT` 来验证。本文件不是一串串口命令，而是说明「为什么不上板」以及「如果未来要修，有哪几条待证方向」。

**红线声明**：本任务全程未上板、未操作 SDR、未发射、未训练、未改冻结模型/门限/标签/波形。

---

## 1. 为什么不上板

1. 所有已测试候选（M1 静默区去 DC、M2 保护区去 DC、M3 均值、M4 逐样本线性漂移、甚至 oracle 去 DC）在主机侧完整重估后，最多 2/24——去直流只把被门拒的 AM-SSB-WC 帧救回来（其训练残差从 0.1066 降到 0.038–0.057 而通过门禁），其余 20/24 帧仍坍缩到两个 SSB 类。**没有能恢复准确率的修正可固化。**
2. 跨会话证据：数字回环（|a|≈1）23/24，两个独立 RF 会话（|a|≈0.031）都 1/24——问题在 RF 信道的低增益 → 大偏置增益（≈1/|a|≈32×），不是板端实现 bug（Phase A 已证明 Host 逐字节复现板端坍缩）。广线性矩阵良态（cond≈1.1），**不是**前版误称的「denom≈0.001 → 10³ 放大」。
3. 因此把一个不改善结果的补丁固化成板端生产链，违反「不得将离线改进称为 RF_PASS」——没有改进可固化。

## 2. 未来可选方向（均需单独授权 + 单独任务书，本任务不执行）

**尚未证明「必须微调」**。以下只是待证方向，不构成结论：

1. **RF 微调**：需用户明确授权「RF 微调/训练」类任务（当前红线禁止训练）。需要更多 RF 采集（多轮、多 SNR、多硬件状态）或带 RF 信道模型（LO 泄漏/漂移/IQ 不平衡增强）的训练数据；在独立 RF 采集上评估——指标仍用冻结 24 类 BF16 真实准确率，0.100 门不变，24 分母不剔除。
2. **更鲁棒的接收恢复（无需训练，优先探索）**：在恢复链中自适应追踪时变直流/LO 泄漏（如逐块估计 + 平滑），前提是只用前导/训练/静默区公共参考、不读原始载荷 IQ 选参，仍满足红线。这是**尚未穷尽**的方向，应先于微调尝试。
3. **扩大 RF 采集**：多轮、多 SNR、多硬件状态，量化时变直流的统计分布，为上述任一方向提供依据。
