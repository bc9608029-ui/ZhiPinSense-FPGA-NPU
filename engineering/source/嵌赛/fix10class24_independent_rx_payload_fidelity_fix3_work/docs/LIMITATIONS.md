# Fix3 局限与边界（LIMITATIONS）

任务：`M29-RML24-FIX10CLASS24-INDEPENDENT-RX-PAYLOAD-FIDELITY-FIX3`

---

## 1. 结论的边界

1. **只否定「实际测试过的」候选，未证明「无修复」或「RF 微调一定能修」**。本任务（完整重估后）否定了静态去直流（M1–M3）、逐样本线性漂移外推（M4）、oracle 去直流（M5 上界）这些**具体的**与类别无关恢复候选——它们最多把端到端准确率从 1/24 提到 2/24（额外恢复被门拒的 AM-SSB-WC 帧），**不能恢复 24 类准确率**。但这**不**排除尚未测试的、仍与类别无关且无需训练的完整恢复方案（如对时变直流/LO 泄漏做自适应追踪，只用前导/训练/静默区公共参考），也**不**证明「RF 微调能恢复准确率」——那是一个待证命题，本任务未执行任何训练。

2. **直流是必要但不充分的病根**。直流是被广线性逆的偏置增益（≈1/|a|≈32×，归一化域；矩阵良态 cond≈1.1）放大到最显眼的症状，但把它压到 0.1j（M1）只能恢复被门拒的 DC 载波帧（source 18），其余帧预测散开到 ASK/APSK/QAM 仍错。底层 RF 劣化更广：噪声、IQ 不平衡、非线性、直流时变漂移。因此本报告**不**把问题归结为单一可加性偏置。

3. **两次 RF 捕获，各 24 帧，每类 1 帧**。结论基于两批独立 RF 捕获：`rml24_fix2_dual_1773374951_244`（主）与 `rml24_independent_v2_dual_1773374217_210`（旧会话交叉验证，review item 4）；另用数字文件回环（`rml24_fix2_v2_file_1773373830_244`）隔离 RF 域。两个 RF 会话都坍缩到 SSB（M0 各 1/24），但样本量仍小，不能外推到所有 RF 环境。

4. **未对 RF 前端建模**。时变直流/LO 泄漏的物理来源（本振泄漏、直流偏移随温度/AGC 漂移）未做硬件级测量，只是从 IQ 数据推断。

5. **oracle 残差 ~19% 未归因**。即便用干净张量 + 最佳增益 + 最佳 DC 做 oracle 去除，BPSK 仍残留 19% 失配（`resid_after_gain_dc`），本任务未逐项分解这 19% 是噪声 / IQ 不平衡 / 非线性 / 残余漂移各占多少。

6. **AM-DSB-WC 在本契约中 DC≈0**。逐类测量发现本冻结契约里 AM-DSB-WC(19) 与 AM-DSB-SC(20) 的载荷均值 ≈ 0（|mean|/rms < 0.001），而 AM-SSB-WC/SC、OOK/ASK 有强直流。这是契约属性，未改动；若未来诊断涉及其「载波」语义，需以契约为准而非调制教科书。

## 4. 下一步建议（供未来任务参考，本任务不执行）

1. **RF 域增强微调**：用真实 RF 采集（或 RF 信道模型 + 已知 LO 泄漏/漂移/IQ 不平衡增强）微调冻结模型，再在独立 RF 采集上评估——需要单独授权、单独任务书。
2. **更鲁棒的接收恢复**：在恢复链中自适应追踪时变直流/LO 泄漏（如逐块估计 + 平滑），但须证明不违反「不读原始载荷 IQ 选参」红线（只能用前导/训练/静默区公共参考）。
3. **扩大 RF 采集**：多轮、多 SNR、多硬件状态，量化时变直流的统计分布。
