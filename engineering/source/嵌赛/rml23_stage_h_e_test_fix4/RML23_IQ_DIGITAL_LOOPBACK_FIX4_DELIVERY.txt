1. 修复的 fix3 仪表缺陷清单
--------------------------------------------------------------------------------
  (a) kind/target_rms 未传播 -> sweep_one_level() 增 kind/target_rms 参数并写入
      SweepLevel；sweep_all_levels() 双层循环传入。

      (length_bits) 再逻辑右移(shift)，仅 is_fully_defined=false 时 mask/sign-extend；
      0xFFE0(-32) 不再被无条件 &0x0FFF 成假 +4064。
  (c) 直接比 counts 可能错 -> 新增 COUNT/NORMALIZED 双域指标，满量程从 DataFormatInfo
      推导(2^(bits-1))，TX16 fs=32768 / RX12 fs=2048 不硬编码。

--------------------------------------------------------------------------------
2. host 镜像 vs 官方 libiio 语义对照
--------------------------------------------------------------------------------
  libiio iio_channel_convert: 复制/端序 -> 容器 shift -> 仅 is_fully_defined=false 时
  sign-extend(signed) / clear-high-bits(unsigned)；is_fully_defined=true 不得无条件
  mask 到 bits。fix4 镜像严格对齐；format_convert_raw_to_host_force_signed 为独立
  诊断视图(标注 force_signed_diagnostic)，非 libiio 镜像、不进生产 convert 路径。

--------------------------------------------------------------------------------
3. count / normalized 双域公式
--------------------------------------------------------------------------------
  count_gain_db      = 20·log10(rx_count_rms / tx_count_rms)
  normalized_gain_db = 20·log10((rx_count/2^(rx_bits-1)) / (tx_count/2^(tx_bits-1)))
  COUNT_DOMAIN_SCALE = normalized ~0 dB 且 count gain 符 TX16/RX12 位宽差(-24.08 dB)。

--------------------------------------------------------------------------------
4. 判责优先级（A→G）与阈值
--------------------------------------------------------------------------------
  A  rx_libiio_diverged            -> LIBIIO_CONVERT_SEMANTICS
  B  capture失败/RX全零/有效档不足 -> NOT_PROVEN
  C  报告解码不一致 且 非报告shift同时恢复corr+尺度+无新削顶 -> FORMAT_MISALIGNMENT
  D  报告格式 corr < 0.9           -> NOT_PROVEN
  E  normalized~0(<=3dB): tx!=rx 位宽且count符位宽差 -> COUNT_DOMAIN_SCALE；同位宽 count~0 -> UNITY
  F  normalized< -3dB              -> FIXED_ATTENUATION
  G  其余                          -> NOT_PROVEN
  阈值: kFidelityCorrThreshold=0.9 / kGainPreservedDb=3.0 / kQuantFloorCounts=2.0；
  有效档 = target_rms>=64 且无削顶且 RX>=量化底噪；corr 尺度不变 -> 错位判据用逻辑增益!=计数增益。
