# 三模式与10条历史记录：实现合同

## 范围

在测试前单目标稳定接收代码及其 UI2/gapfix 修订上建立独立软件候选。不采用失败 AC 的多目标 tracker、ReceiverEntry、公平调度或列表解析器。不修改模型、two-DC 恢复、相干平均算法、公共帧或 FPGA 位流。

来源身份见 evidence/BASELINE_IDENTITY.json；候选源身份见 evidence/CANDIDATE_SOURCE_IDENTITY.json；差异见 evidence/CHANGED_FILES.json。电脑上本地源不能证明板端当前正式服务就是同一版本，板测前要核对实际 ExecStart 与 SHA。

## 三种模式

| UI | 线协议 | 行为 |
|---|---|---|
| FIXED | FIXED | 原定频恢复、八段相干平均、NPU推理 |
| SEARCH LOCK | BAND_SCAN | 原范围全扫选公共参考得分最高候选，居中确认后持续锁定；原5次且1秒连续失锁迟滞后重扫 |
| SWEEP | CONTINUOUS_SCAN | 每轮只检查一个扫描点；命中后重调谐到估计中心、刷新采集并确认公共帧；恢复/推理后继续下一点，到末尾重新开始 |

界面仍五页：识别、参数、瀑布、星座（底部 IQ PLOT）、模式/频率输入。AUTO_LOCK 不作为可选用户模式；C++保留旧token兼容不等于Python启用第四种模式。

巡扫不能同时接收全部范围。命中需额外调谐/采集/推理时间；步长越小、范围越大耗时越长。UI显示最近识别频率及本机收到结果时间，扫描进度由接收端 GET_TUNING 返回，不把旧识别结果当当前LO处实时数据。瀑布遇目标中心变化超过10kHz清空，防止不同中心横轴混叠；它不是整个扫描范围的拼接宽带瀑布。

发现门0.10；发现CFO须有限且不超过±1.152MHz；中心须处于扫描范围；居中确认门0.10、CFO不超过±1000Hz。只用公共参考，不读TX时序、频点真值、类别、载荷模板。门限沿用既有检测条件，不能调成看标签选目标。

显式拒绝明显超出可用带宽的CFO并居中确认，不等于已经消除所有采样率别名或真实杂散。真实多频点源已有约−28dBc副本报告，须独立短测；不能把副本一律算RX伪目标。

## 历史窗口

第一页 HISTORY 打开。最多10条，每页5条，共两页；相近频率（10kHz内）的记录更新最近识别、类别、Top3、模式和累计有效结果数，并移到前面，不逐帧新增；第11个频率移除最旧项。

这是最近频率摘要，不识别发射机身份，不能区分同频设备；10kHz是UI合并策略，不是射频分辨率承诺。当前实现同频类别变化更新摘要，不额外生成无限事件记录。

记录时间为UI收到有效分类的本机时间，非发射时刻；计数是有效分类结果数，非独立源波形数或数据集样本数。只有真实Live、有效24类概率、有效频率才进入历史；静默、恢复失败、Mock不填猜测记录。

窗口打开时固定列表快照，关闭重开刷新，避免结果更新导致手指选中错误行。详情为固定副本，只显示频率、时间、模式、次数和Top3；不保存/显示历史IQ，不把当前参数和星座套用到历史。清空有窗口内确认（不是开发过程向用户请求yes/no）；实时接收继续。

--history-file提供持久化。每5秒或用户动作/正常退出保存，临时文件重命名；突然断电可能损失最后几秒更新，不宣称fsync级断电持久性。损坏文件保留，告警后本次用内存记录，不悄悄覆盖。需要已有可写父目录。新监督器对同一历史路径加锁；禁止多个UI共享同一历史文件。

## 仍固定的条件

采样率2.56MS/s、RX手动35dB、滤波18MHz、同一公共头尾、1024载荷重复8段、模型[8,2,1024]。UI默认频率范围2.3～2.5GHz；步长>0且≤2.304MHz，最多101扫描点。增益/带宽自适应和1/2/4/8重复消融没有加入本轮。

目前高识别率属于历史单目标同轴配置，不是新候选成绩；无新RF准确率、无多参数或天线通用性证明，未知类别也不保证可靠拒识。

## FPGA任务的最小修订

B线核心FFT/Hann/PSD/双缓冲/PSPL不推翻。验收基线从失败AC改为本三模式候选验收后的稳定版；增加每帧实际LO、帧号、时间戳对应检查，换频丢弃旧帧，软件回退与same-IQ对照保留。不预判B实际代码改动量；本轮未改B代码、未综合新位流、未上板。
